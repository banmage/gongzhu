# 中式拱猪（2v2 对家版）亮牌规则 V1.0

> **状态**：冻结候选（提案稿）  
> **定位**：统一描述“谁能亮、亮什么、AI 如何决定亮不亮、亮几张、如何采样、与自动亮/计分如何衔接”。  
> **依据**：`rules/模块A~D`、`rules/yaml 中式拱猪 2v2对家版 AI亮牌决策规则配置.txt`、`docs/中式拱猪_对家双人队赛_SRS_V3.1.md`。  
> **说明**：本文件只定义规则，不包含实现改动；实现时应以本文件第 10 节配置为唯一参数源。

## 0. 相对上一版的关键修订

| 编号 | 修订 | 原因 |
| --- | --- | --- |
| R1 | 分值临界全部改为**相对分差** \(x=(S_{me}-S_{op})/S_{ref}\) | 绝对分值会把“双方都 +900”或“双方都 -900”误判为极端局面 |
| R2 | 分支概率改为**强度插值**，不再使用 `2m-1` 直接套 Sigmoid | 避免刚进入分支时概率突降，与“越接近临界越应行动”相反 |
| R3 | 猪/羊/变压器张数明确为**对应花色长度** | 原文把“关键牌张数”和“花色长度”混用，无法计算 |
| R4 | `k_top` 统一为 `#A + 0.5#K + 0.5#Q` | 原文 KQ 示例与定义冲突 |
| R5 | 单张黑桃亮猪取消“常规禁亮”，改用可配置因子 | 与“免窝猪”规则配套，风险已降低 |
| R6 | 零风险变压器的“第 1–2 轮时间窗”删除 | 当前规则是出牌前一次性亮牌，不存在轮次内二次决策 |
| R7 | 互斥改为**最终集合统一因子**，不做顺序连乘 | 消除贪心加入顺序导致的概率不一致 |
| R8 | 模块 C 默认关闭（`F_slam=1`） | 四个满贯概率尚无可用估算器，先保证可执行 |
| R9 | 明确一次性亮牌、第四张自动亮、读秒 5–60/不限时的边界 | 与当前产品规则对齐 |

## 1. 适用范围

1. 适用于 2v2 对家队的四人拱猪，每副牌发牌后、出牌前的**亮牌阶段**。
2. 适用于 AI 座位的亮牌决策，也适用于校验人类座位的提交是否合法。
3. 不包含出牌阶段 AI 策略；首轮限制、垫牌、跟牌只作为亮牌后的既有规则引用。
4. 满贯结算、变压器倍率、窝猪等计分规则以 SRS V3.1 第 5 章为准，本文件只在亮牌决策中引用其风险方向。

## 2. 术语与符号

| 术语 | 定义 |
| --- | --- |
| 关键牌 | ♠Q 猪、♦J 羊、♣10 变压器、♥A 红桃 A |
| 亮牌 | 玩家在亮牌阶段公开声明自己持有并点亮某张关键牌 |
| 亮猪者 | 本副牌中亮了 ♠Q 的玩家 |
| 窝猪 | 亮猪者本人最终收下 ♠Q，猪分记 -400 |
| 免窝猪 | 亮猪时手中仅 1 张黑桃（即 ♠Q 本身），本人自收仍按亮猪 -200，不记窝猪 |
| 全红 | 单个玩家收齐全部 13 张红桃 |
| 满贯 | 单个玩家集齐猪、羊、变压器、全部 13 张红桃；触发后本队立即赢下本局 |
| 自动亮 | 已亮 3 张关键牌后，按配置自动补齐第 4 张 |
| 亮牌信息模式 | `open`：提交后立即可见；`hidden`：亮牌阶段结束才公开 |

符号：

| 符号 | 含义 |
| --- | --- |
| \(S_{me}\) | 本队当前总分 |
| \(S_{op}\) | 对方队当前总分 |
| \(S_{ref}\) | 相对分值尺度，默认 1000 |
| \(x\) | 相对分差，\(x=(S_{me}-S_{op})/S_{ref}\)，计算时截断到 \([-1,1]\) |

## 3. 输入信息与硬约束

### 3.1 AI 可见信息

AI 座位**只能**使用以下信息：

1. 自己的 13 张手牌；
2. 本队与对方队的当前总分 \(S_{me},S_{op}\)；
3. 本副牌序号、发牌种子派生值；
4. 已亮牌信息：
   - `open` 模式：已公开的具体牌种；
   - `hidden` 模式：只允许使用“已提交亮牌数量”，不得使用牌种；
5. 本局配置（阈值、开关、读秒）；
6. 已打出的公共牌（本副牌亮牌阶段尚无出牌，通常为空）。

**禁止**：读取搭档手牌、读取对方手牌、读取未公开的提交内容、读取未来发牌结果。

### 3.2 合法性硬约束

以下约束优先于任何概率与采样：

1. 只能亮**自己手中实际持有**的关键牌。
2. 同一张关键牌全局最多被亮一次。
3. 亮牌是出牌前的**一次性快照**；亮牌阶段结束后不得追加、撤销或改亮。
4. 人类超时未提交视为“不亮”；AI 不使用读秒，由调度器直接决策。
5. `autoLightLastOne=false` 时，即使已亮 3 张也不自动补齐第 4 张。
6. 自动亮由服务端在“全员提交后或亮牌截止时”统一判定，属于规则行为，不参与本文件的概率采样。
7. 首轮限制对亮牌（含自动亮）照常生效：受限制亮牌不能主动领出，只能在跟牌且仅剩该牌时被迫出。
8. 亮牌只影响拿牌者个人计分；满贯为团队结果，属于例外。

### 3.3 与读秒的关系

| 配置值 | 行为 |
| --- | --- |
| `lightSeconds ∈ [5,60]` | 倒计时结束自动提交当前选择（通常为空） |
| `lightSeconds = 0` | 无读秒，不自动提交，等待玩家手动确认 |
| `playSeconds` | 同上，作用于出牌阶段，不影响亮牌概率 |

AI 决策必须在同一回合内完成，不依赖倒计时。

## 4. 相对分值体系

### 4.1 定义

\[
\Delta = S_{me}-S_{op},\qquad
x=\mathrm{clamp}\left(\frac{\Delta}{S_{ref}},-1,1\right)
\]

- \(x>0\)：本队领先；\(x<0\)：本队落后；\(x=0\)：均势。
- 默认 \(S_{ref}=1000\)，即 \(x=1\) 表示领先 1000 分，\(x=-0.6\) 表示落后 600 分。
- 绝对胜负线 \(\pm1000\) **只用于判定对局是否结束**，不再直接作为 AI 分支阈值。

### 4.2 为什么不用绝对分值

| 场景 | 绝对分值旧逻辑 | 相对分值新逻辑 |
| --- | --- | --- |
| 双方均 +900 | 可能同时触发“我方冲锋”和“敌方胜线封锁” | \(x=0\)，常规局 |
| 双方均 -900 | 可能同时触发双方“殉爆” | \(x=0\)，常规局 |
| 我方 -900，对方 -100 | 触发殉爆 | \(x=-0.8\)，触发殉爆 |
| 我方 +900，对方 +100 | 触发冲锋 | \(x=+0.8\)，触发冲锋 |

### 4.3 分支判定

按顺序判定，命中即停止：

| 顺序 | 分支 | 条件 | 旗标 | 策略意图 |
| --- | --- | --- | --- | --- |
| 1 | 殉爆 | \(x \le -0.60\) | `desperate` | 损失已接近饱和，拉对方一起出局 |
| 2 | 绝境博弈 | \(-0.60 < x \le -0.30\) | `gamble` | 落后但未饱和，争取拖平/翻盘 |
| 3 | 冲锋 | \(x \ge +0.60\) | `rush` | 领先接近终点，放大优势直接冲线 |
| 4 | 常规 | 其余 | `normal` | 按基准概率谨慎亮牌 |

补充硬否决：

\[
x \le -0.80 \;\Rightarrow\; P_{base,sheep}=0
\]

理由：对方已领先 800 分以上，亮羊一旦被对方收下，可能直接送对方越过 +1000。该否决优先于所有分支和修正。

## 5. 模块 A：相对分值基准概率

### 5.1 常规模式

\[
\sigma(z)=\frac{1}{1+e^{-z}}
\]

| 牌 | 公式 | 初值 |
| --- | --- | --- |
| 猪 | \(P_{base,pig}=\sigma(k_{pig}x-b_{pig})\) | \(k_{pig}=3.0,\ b_{pig}=0.8\) |
| 红桃 A | \(P_{base,hA}=\sigma(k_{hA}x-b_{hA})\) | \(k_{hA}=4.0,\ b_{hA}=1.2\) |
| 羊 | \(P_{base,sheep}=\sigma(-k_{sheep}x+b_{sheep})\) | \(k_{sheep}=3.0,\ b_{sheep}=0.2\) |
| 变压器 | \(P_{base,trans}=\sigma(k_{trans}x-b_{trans})\) | \(k_{trans}=2.5,\ b_{trans}=0.8\) |

方向说明：

- 领先时（\(x>0\)），猪、红桃 A、变压器概率上升：用于向落后方施压；
- 落后时（\(x<0\)），羊概率上升：正分牌是追分工具；
- 落后时猪、红桃 A 概率下降：避免自伤；
- 变压器在落后时保持低位，只有进入殉爆/冲锋分支才被强制抬升。

均势参考值：猪 ≈0.31，红桃 A ≈0.23，羊 ≈0.55，变压器 ≈0.31。

### 5.2 分支强度

分支强度均归一化到 \([0,1]\)，用于在常规值与分支目标值之间插值，保证阈值处连续。

**殉爆强度**（\(x \le -0.60\)）：

\[
m=\mathrm{clamp}\left(\frac{-x-0.60}{0.40},0,1\right)
\]

\(m=0\)：刚进入殉爆区；\(m=1\)：已贴到 -1000。

**绝境强度**（\(-0.60 < x \le -0.30\)）：

\[
g=\mathrm{clamp}\left(\frac{-x-0.30}{0.30},0,1\right)
\]

**冲锋强度**（\(x \ge +0.60\)）：

\[
n=\mathrm{clamp}\left(\frac{x-0.60}{0.40},0,1\right)
\]

### 5.3 分支概率

插值公式：

\[
P^{branch}_X=P^{reg}_X+\lambda\cdot\left(P^{target}_X-P^{reg}_X\right)
\]

其中 \(\lambda\) 为对应分支强度，\(P^{target}_X\) 为该分支下的目标概率。

| 分支 | 牌 | 目标值 \(P^{target}\) | 处理 |
| --- | --- | --- | --- |
| 殉爆 `desperate` | 变压器 | 0.95 | \(P=P^{reg}+m(0.95-P^{reg})\) |
| 殉爆 `desperate` | 红桃 A | 0.85 | \(P=P^{reg}+m(0.85-P^{reg})\) |
| 殉爆 `desperate` | 猪 | 0.75 | \(P=P^{reg}+m(0.75-P^{reg})\) |
| 殉爆 `desperate` | 羊 | — | 维持常规值；若 \(x\le-0.80\) 仍置 0 |
| 绝境 `gamble` | 猪 | 0.65 | \(P=P^{reg}+g(0.65-P^{reg})\) |
| 绝境 `gamble` | 红桃 A | 0.60 | \(P=P^{reg}+g(0.60-P^{reg})\) |
| 绝境 `gamble` | 变压器 | 0.70 | \(P=P^{reg}+g(0.70-P^{reg})\) |
| 绝境 `gamble` | 羊 | — | 维持常规值 |
| 冲锋 `rush` | 变压器 | 0.95 | \(P=P^{reg}+n(0.95-P^{reg})\) |
| 冲锋 `rush` | 猪 | — | \(P=P^{reg}\cdot(1-n)\) |
| 冲锋 `rush` | 红桃 A | — | \(P=P^{reg}\cdot(1-n)\) |
| 冲锋 `rush` | 羊 | 0.70 | \(P=P^{reg}+n(0.70-P^{reg})\) |

说明：

1. 冲锋阶段猪与红桃 A 只减不增，避免在临界点自伤。
2. 殉爆阶段羊不主动抬升：正分牌救不了濒临出局的局面，且可能被对方收走。
3. 所有结果最后仍要经过 `clamp(0,1)`。

### 5.4 下游约束（防止后续模块反向抵消）

| 旗标 | 约束 |
| --- | --- |
| `desperate` | 变压器、红桃 A 的 \(F_{card}\) 下限为 1.0，不得以“我方负分高”为由压低 |
| `rush` | 猪、红桃 A 的 \(F_{card}\) 上限为 1.0，不得因“牌型完美”而抬升 |
| 任意 | \(P_{base,sheep}=0\) 为全局否决，任何因子都不得使其复活 |

## 6. 模块 B：牌型与牌点修正

### 6.1 张数口径

\(n_x\) 是**目标花色长度**，不是关键牌张数：

| 牌种 | 花色 | \(n_x\) |
| --- | --- | --- |
| 猪 | 黑桃 | 手中黑桃张数 |
| 羊 | 方块 | 手中方块张数 |
| 变压器 | 梅花 | 手中梅花张数 |
| 红桃 A | 红桃 | 不查张数表，改用 \(F_{hA}\) |

### 6.2 张数因子 \(F_{cnt}\)

**猪：**

| \(n\) | 1 | 2 | 3 | 4 | ≥5 |
| --- | --- | --- | --- | --- | --- |
| \(F_{cnt,pig}\) | 0.30 | 0.42 | 0.55 | 1.00 | 1.60 |

特殊规定：

- \(n=3\) 时强制落在 \([0.55,0.60]\)，常规模式视为“不考虑亮”；
- 单张黑桃例外见 6.5，不直接套 0.30。

**变压器：**

| \(n\) | 1 | 2 | 3 | 4 | ≥5 |
| --- | --- | --- | --- | --- | --- |
| \(F_{cnt,trans}\) | 0.30 | 0.50 | 0.85 | 1.25 | 1.45 |

- \(n=3\) 且不满足零风险时，\(F_{cnt,trans}\le0.90\)；
- 零风险时取 \(\max(1.30,F_{cnt,trans})\)。

**羊：**

| \(n\) | 1 | 2 | 3 | 4 | 5 | ≥6 |
| --- | --- | --- | --- | --- | --- | --- |
| \(F_{cnt,sheep}\) | 0.60 | 0.80 | 1.00 | 1.20 | 1.40 | 1.55 |

### 6.3 红桃 A 可行性 \(F_{hA}\)

\[
F_{hA}=\sigma\left(\lambda_1(L_h-4)+\lambda_2(k_{top,h}-1)-\lambda_3 s_{low,h}\right)
\]

初值：\(\lambda_1=0.9,\ \lambda_2=1.5,\ \lambda_3=0.30\)。

其中：

- \(L_h\)：红桃张数；
- \(k_{top,h}=\#A+0.5\#K+0.5\#Q\)（仅统计红桃）；
- \(s_{low,h}\)：红桃中可先甩出的小牌张数（J 及以下）。

典型读数（统一口径后）：

| 红桃结构 | \(L_h\) | \(k_{top,h}\) | \(s_{low,h}\) | \(F_{hA}\) |
| --- | --- | --- | --- | --- |
| 仅 A | 1 | 1.0 | 0 | ≈0.063 |
| A + 2 小 | 3 | 1.0 | 2 | ≈0.182 |
| K + Q | 2 | 1.0 | 0 | ≈0.142 |
| A + 2 大 + 3 小 | 6 | 1.5 | 3 | ≈0.839 |

短红桃带 K/Q 的低分不直接影响亮牌，由 6.4 的 \(F_{ctrl,hA}\) 补偿。

### 6.4 牌点因子与控牌因子

**牌点权重：**

| 牌点 | A | K | Q | J | 10 | 其余 |
| --- | --- | --- | --- | --- | --- | --- |
| \(w\) | 1.00 | 0.85 | 0.65 | 0.45 | 0.30 | 0.15 |

\[
T=\max_i w(c_i),\qquad D=\frac{1}{n}\sum_i w(c_i)
\]

\[
F_{pts}=1+\gamma\tanh\left(\delta(\kappa T+(1-\kappa)D-\theta)\right)
\]

初值：\(\gamma=0.80,\ \delta=6,\ \kappa=0.70,\ \theta=0.50\)，结果截断到 \([0.20,1.80]\)。

**门控指数：**

\[
Q=\sigma\left(\mu_1(L-5)+\mu_2(k_{top}-1)+\mu_3 s_{low}\right)
\]

初值：\(\mu_1=0.80,\ \mu_2=1.20,\ \mu_3=0.40\)。

\[
F_{ctrl}=\sigma\left(\eta(Q-0.5)\right),\qquad \eta=3.0
\]

红桃门额外补偿：

\[
F_{ctrl,hA}=\max\left(F_{ctrl},\ \sigma\left(\nu_1(2-L_h)+\nu_2(k_{top,h}-1.5)\right)\right)
\]

初值：\(\nu_1=1.0,\ \nu_2=2.0\)。

### 6.5 单张黑桃亮猪例外

若亮猪者手中黑桃恰好 1 张（必为 ♠Q），则：

1. 取消“猪仅 1 张常规禁亮”的结构性否决；
2. 张数因子取
   \[
   F_{cnt,pig}=\max\left(F_{cnt,pig},\ F_{single\_spade\_pig}\right)
   \]
   初值 \(F_{single\_spade\_pig}=0.45\)；
3. 仍按正常阈值参与采样；
4. 计分时适用“免窝猪”：本人自收 ♠Q 记亮猪 -200，不记 -400；
5. 若本人未收 ♠Q，按普通亮猪规则由收牌者承担 -200。

该例外只改变“是否敢亮”，不改变亮牌后的分值。

### 6.6 零风险变压器

**风险张集合：**

- 红桃门持 A 或 K；
- 猪门持 A 或 K；
- 任一门的顶尖牌，且该门长度 \(\le2\)。

**零风险条件**：上述集合为空。

命中时：

- \(F_{cnt,trans}=\max(1.30,F_{cnt,trans})\)；
- \(F_{card,trans}\) 下限为 1.30；
- **不设轮次时间窗**：亮牌阶段一次性决策，命中即生效。

### 6.7 结构性否决

| 情形 | 处理 |
| --- | --- |
| 红桃仅 A（或 A + ≤2 小牌），且无 K、Q | \(F_{hA}\le0.10\)，常规/冲锋分支禁亮；仅 `desperate` / `gamble` 可启用 |
| 猪仅 1 张黑桃 | 按 6.5 例外处理，不直接禁亮 |
| 猪 3 张 | \(F_{cnt}\in[0.55,0.60]\)，常规不考虑亮 |
| 变压器 3 张且非零风险 | \(F_{cnt}\le0.90\) |
| \(x\le-0.80\) 的羊 | 全局禁亮，任何因子不得复活 |

### 6.8 牌型因子合成

\[
F_{card}=\mathrm{clamp}\left(F_{cnt}\cdot F_{pts}\cdot F_{ctrl},0.05,2.50\right)
\]

- 猪、羊、变压器使用各自花色的 \(F_{cnt},F_{pts},F_{ctrl}\)；
- 红桃 A 使用 \(F_{hA}\) 替代 \(F_{cnt}\)，并使用 \(F_{ctrl,hA}\)；
- 各类牌独立计算，不做链式推导。

## 7. 模块 C：满贯预判修正（可选，默认关闭）

### 7.1 开关

```yaml
module_c:
  enabled: false
```

- `enabled=false`：\(F_{slam,X}=1\)，跳过本节；
- `enabled=true`：按 7.2 计算，四个满贯概率必须由可复现的估算器提供；
- 在估算器未实现前，禁止开启，避免用拍脑袋概率放大波动。

### 7.2 修正公式

\[
F_{slam,pig}=(1-w_{opp,pig}P_{opp\_dragon})(1+w_{self,pig}P_{self\_dragon})
\]

\[
F_{slam,hA}=(1-w_{opp,hA}\max(P_{opp\_allred},P_{opp\_dragon}))
(1+w_{self,hA}\max(P_{self\_allred},P_{self\_dragon}))
\]

\[
F_{slam,sheep}=(1-w_{opp,sheep}P_{opp\_dragon})(1+w_{self,sheep}P_{self\_dragon})
\]

\[
F_{slam,trans}=(1-w_{opp,trans}\max(P_{opp\_allred},P_{opp\_dragon}))
(1+w_{self,trans}\max(P_{self\_allred},P_{self\_dragon}))
\]

权重：

| 旗标 | \(w_{opp,pig}\) | \(w_{self,pig}\) | \(w_{opp,hA}\) | \(w_{self,hA}\) | \(w_{opp,sheep}\) | \(w_{self,sheep}\) | \(w_{opp,trans}\) | \(w_{self,trans}\) |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `normal` | 0.75 | 0.25 | 0.85 | 0.35 | 0.50 | 0.40 | 0.80 | 0.50 |
| `gamble` | 0.40 | 0.30 | 0.50 | 0.40 | 0.30 | 0.45 | 0.40 | 0.55 |
| `desperate` | 0.15 | 0.40 | 0.20 | 0.45 | 0.10 | 0.45 | 0.05 | 0.70 |
| `rush` | 0.60 | 0.40 | 0.70 | 0.50 | 0.40 | 0.60 | 0.50 | 0.80 |

截断：

| 因子 | 区间 |
| --- | --- |
| \(F_{slam,pig}\) | \([0.20,1.60]\) |
| \(F_{slam,hA}\) | \([0.15,1.70]\) |
| \(F_{slam,sheep}\) | \([0.30,1.80]\) |
| \(F_{slam,trans}\) | \([0.20,2.00]\) |

约束：

1. 模 C 只做乘法修正，不得推翻模块 A 的硬否决；
2. 殉爆分支下削弱敌方风险压制，这是殉爆策略的一部分；
3. 冲锋分支下提高变压器、羊的满贯加成；
4. 亮牌决策是亮牌阶段的一次性快照，出牌阶段不再回溯修改。

## 8. 模块 D：综合判定、互斥与采样

### 8.1 概率合成

\[
P_{raw,X}=\mathrm{clamp}\left(P_{base,X}\cdot F_{card,X}\cdot F_{slam,X},0,1\right)
\]

### 8.2 互斥因子

互斥只对**最终集合**生效一次，不做“每加入一张全体连乘”。

\[
F_{mutex}(S)=\min_{\{X,Y\}\subseteq S}\ \text{coef}(X,Y)
\]

若 \(|S|\ge3\)，再与“三张及以上”系数取较小值；\(|S|\le1\) 时 \(F_{mutex}=1\)。

系数表：

| 组合 | `normal` | `gamble` | `desperate` | `rush` |
| --- | --- | --- | --- | --- |
| 猪 + 红桃 A | 0.50 | 0.65 | 0.85 | 0.40 |
| 猪 + 羊 | 0.75 | 0.82 | 0.90 | 0.80 |
| 猪 + 变压器 | 0.60 | 0.70 | 0.88 | 0.50 |
| 红桃 A + 羊 | 0.70 | 0.78 | 0.90 | 0.75 |
| 红桃 A + 变压器 | 0.55 | 0.68 | 0.88 | 0.45 |
| 羊 + 变压器 | 0.85 | 0.88 | 0.92 | 0.95 |
| 三张及以上 | 0.35 | 0.50 | 0.75 | 0.30 |

### 8.3 数量上限

| 旗标 | \(N_{max}\) |
| --- | --- |
| `normal` | 2 |
| `gamble` | 2 |
| `desperate` | 3 |
| `rush` | 2 |

### 8.4 采样阈值

| 牌种 | `normal` | `gamble` | `desperate` | `rush` |
| --- | --- | --- | --- | --- |
| 猪 | 0.60 | 0.45 | 0.25 | 0.70 |
| 红桃 A | 0.65 | 0.50 | 0.25 | 0.75 |
| 羊 | 0.45 | 0.40 | 0.30 | 0.35 |
| 变压器 | 0.55 | 0.45 | 0.20 | 0.30 |

阈值作用于 \(P_{eff}=P_{raw}\cdot F_{mutex}(S)\)。

### 8.5 候选构建（顺序无关）

1. 对四类牌分别计算 \(P_{raw}\)。
2. 过滤硬禁止：非本人持有、全局已亮、A 模块硬否决、红桃 A 结构性禁亮、冲锋禁猪+红桃 A 同亮。
3. 按 \(P_{raw}\) 从高到低逐个尝试加入集合 \(S\)。
4. 每加入一张前，计算加入后的 \(F_{mutex}(S\cup\{X\})\)，要求：
   \[
   P_{raw,X}\cdot F_{mutex}(S\cup\{X\})\ge T_X
   \]
   且 \(|S\cup\{X\}|\le N_{max}\)。
5. 通过则加入，否则放弃；继续尝试下一张。
6. 最终对 \(S\) 统一应用一次 \(F_{mutex}(S)\)，得到 \(P_{eff,X}\)。

### 8.6 随机采样

对 \(S\) 中每个牌种 \(X\)：

1. 生成 \(r_X\sim U(0,1)\)；
2. 若 \(r_X\le P_{eff,X}\)，则亮 \(X\)；
3. 累计达到 \(N_{max}\) 即停止；
4. 随机数必须由“发牌种子 + 座位 + 副序号 + 牌种”派生，保证可复现。

调试模式：

```yaml
sampling:
  mode: random   # random | threshold
```

- `threshold`：当 \(P_{eff,X}\ge T_X\) 即亮，不做随机；
- `random`：按 8.6 采样；
- 人机对战默认 `random`，自动化测试默认 `threshold`。

### 8.7 硬禁止清单

1. A 模块 \(P_{base,sheep}=0\) 时禁止亮羊；
2. `rush` 分支禁止同时亮猪与红桃 A；
3. 同一张牌不能重复亮；
4. `desperate` 分支无额外组合禁令，仅受 \(N_{max}=3\) 约束；
5. 不持有该牌不得亮；
6. 已亮 3 张后的第 4 张只由 `autoLightLastOne` 决定，不进入本模块。

## 9. 与游戏规则的衔接

### 9.1 一次性亮牌

1. 发牌后进入亮牌阶段，所有玩家同时提交。
2. 提交内容只包含“亮哪些关键牌”，不包含出牌计划。
3. 亮牌阶段结束后统一揭晓，进入出牌阶段。
4. 不设“出牌中再次亮牌”；模块 B 的轮次时间窗、模块 C 的动态刷新均不适用于当前产品。

### 9.2 第四张自动亮

1. 自动亮开关为 `autoLightLastOne`，默认 `true`。
2. 判定时机：全员提交后或亮牌截止时。
3. 触发条件：四张关键牌已亮 3 张且开关开启。
4. 自动亮由服务端执行，不经过概率采样，不受 \(N_{max}\) 限制。
5. 关闭时，第 4 张保持未亮，后续计分按未亮处理。
6. 自动亮的猪若本人自收，算窝猪；但若满足“单张黑桃免窝猪”条件，仍适用免窝猪例外。

### 9.3 亮牌后的计分引用

| 亮牌 | 计分影响 |
| --- | --- |
| 亮猪 | 猪分 -200；亮猪者自收且非免窝猪 → -400 |
| 免窝猪 | 亮猪者仅 1 张黑桃且自收 → 仍 -200 |
| 亮羊 | 羊分 +200 |
| 亮红桃 A | 全场所有选手红桃分值 ×2 |
| 亮变压器 | 非独拿时倍率 ×2→×4；独拿 +50→+100 |

### 9.4 信息模式

- `lightInfoMode=open`：提交后立即可见，AI 可使用已亮牌种；
- `lightInfoMode=hidden`：亮牌阶段结束才公开，AI 只能使用“已提交数量”；
- 默认值应与产品当前实现一致；若从 `open` 切换到 `hidden`，只影响模块 D 的输入，不改变概率公式。

## 11. 决策伪代码

```text
function decideLight(seat, hand, S_me, S_op, litSet, config):
    # 1. 相对分与分支
    x = clamp((S_me - S_op) / config.s_ref, -1, 1)
    flag = classify(x)

    # 2. 基准概率
    P = moduleA(x, flag, config)

    # 3. 硬否决与合法性
    if x <= config.sheep_veto_threshold:
        P.sheep = 0
    held = keyCardsIn(hand)
    forbidden = allLitCards - litSet  # 全局已亮
    P = removeUnavailable(P, held, forbidden)
    P = applyStructuralBan(P, hand, flag)

    # 4. 牌型修正
    F = moduleB(hand, seat, flag)
    P_raw = clamp(P * F.card * F.slam, 0, 1)

    # 5. 候选集合
    candidates = sortDesc(P_raw)
    S = []
    for X in candidates:
        if X.pairedWithForbidden(S, flag): continue
        if len(S) >= config.n_max[flag]: break
        f = mutex(S + [X], flag)
        if P_raw[X] * f >= config.threshold[flag][X]:
            S.append(X)

    # 6. 统一互斥
    f = mutex(S, flag)
    P_eff = {X: P_raw[X] * f for X in S}

    # 7. 采样
    result = []
    for X in S:
        if config.sampling.mode == "threshold" or rng(X) <= P_eff[X]:
            result.append(X)
        if len(result) >= config.n_max[flag]: break
    return result
```

## 14. 结论

1. V1 保留 A→B→C→D 的分层：分数基准、牌型修正、满贯修正、综合约束。
2. 分值临界完全使用相对分差，绝对 \(\pm1000\) 只作为对局终止线。
3. 所有分支概率在阈值处连续，避免“刚进入分支反而更保守”。
4. 模块 C 作为可选增强，默认关闭，保证规则可执行。
5. 亮牌与自动亮、免窝猪、读秒、首轮限制的边界已明确。
6. 本文件可作为实现与测试的唯一规则依据；实现前只需确认第 10 节参数。

## 1. 项目概述
### 1.1 目标
实现标准中式拱猪 4人对家2v2团队赛，支持真人+AI混合对局；严格遵循传统拱猪核心计分、亮牌、满贯、猪头规则；优先保证规则正确性、可复现、可测试。

### 1.2 一期排除范围（不做）
- 单人模式、自由随机组队
- 差值分计分模式
- 搭档信号、暗号提示系统
- 高级AI概率推演、读牌、欺骗策略
- 自定义自定义分牌分值（分值固定）

### 1.3 核心胜负逻辑简述
4人分两队，同队两人分数合并为团队分；通过收墩获取分牌，触发窝猪、全红、变压器倍率、满贯特殊效果；副牌结算后判断是否画猪头；一局内猪头累计；整盘结束按赛制判定最终胜负。

## 2. 术语与定义
| 术语 | 定义 |
|---|---|
| 座位 | 4座位：北、南、东、西；**北↔南一队，东↔西一队（对家固定搭档）** |
| 副牌 | 一次完整发牌、亮牌、13墩出牌、副牌结算；一局由1至多副牌组成 |
| 墩 | 一轮4人依次出牌，4张牌组成一墩；赢墩者获得本墩所有分牌，获得下一轮领出权 |
| 本副收得分牌 | 玩家在本副牌各墩赢墩后收集到的分牌集合；**≠手牌**（重点：满贯判定基于该集合，不是发到手的手牌） |
| 团队原始和 | 同队两名玩家本副个人分之和；一期团队累计分采用该值持续累加 |
| 本局累计团队分 | 同一局内，每一副牌结算后的【团队原始和】持续累加 |
| 猪头 | 惩罚标记，按副牌结算条件给队伍增加猪头；猪头在**同一局内持续累计，新局清零** |
| 猪 ♠Q | 分牌，基础分值 -400 |
| 羊 ♦J | 分牌，基础分值 +100 |
| 变压器 ♣10 | 特殊倍率牌，拿到后可对个人分进行倍率放大 |
| 红桃A~K | 13张红桃，单张红桃分值：A:-100，K:-80，Q:-60，J:-40，10~2各-20 |
| 亮牌（暗亮） | 亮牌阶段玩家秘密标记关键牌；亮牌信息在亮牌阶段结束后统一揭晓，打牌过程中客户端不能提前泄露 |
| 满贯 | 最高优先级特殊牌型，触发后直接终止当前副牌结算，跳过普通计分、窝猪、全红计算 |

## 3. 玩家与座位模型
1. 固定组队：北+南一队；东+西一队，组队不可在局中切换。
2. 座位类型：真人玩家 / AI机器人，支持混合。
3. 一局一旦启动，队伍绑定直到本局结束；不支持中途换队友。

---

## 4. 全局主流程
```
对局开局 → 选择赛制（5局 / 8局）→ 开启【局】
├─ 开启一副牌
│  ├─ 洗牌 + 发牌，每人13张手牌
│  ├─ 亮牌阶段（限时）→ 亮牌阶段结束，统一揭晓全部亮牌结果
│  ├─ 出牌阶段：逐墩打牌，直到【13墩全部打完】
│  ├─ 副牌结算：
│  │  ├─ 第一步：满贯判定（最高优先级）
│  │  ├─ 未满贯：执行窝猪→全红→变压器→个人分计算
│  │  ├─ 计算两队本副团队原始和，累加入本局团队累计分
│  │  └─ 猪头判定，更新两队本局猪头计数
│  ├─ 分支A：本副触发满贯 → 本局直接结束，不再开启新副牌
│  └─ 分支B：未触发满贯，且本局未结束 → 开启下一副牌，领出权继承
├─ 本局结束判断（满贯触发 / 猪头条件满足）
└─ 整盘所有局打完，按赛制判定盘胜负
```

> 补充约束：**只有13墩全部打完，才进入常规副牌结算流程；满贯属于提前终止副牌结算路径**

## 5. 发牌、领出权规则
1. 发牌：52张牌均分，每人固定13张，无底牌。
2. 新局的**第一副牌**：由持有 ♣2 的玩家率先领出第一墩。
3. 非首副（同一局内上一副没有满贯）：**上一副最后赢到猪♠Q的玩家，为本副第一墩领出人**。
4. 满贯分支：上一副触发满贯 → 本局直接结束；新局重新按 ♣2 规则领出。
> 备注：拱猪规则下，猪♠Q一定会被某玩家赢墩收走，不存在无人拿到猪的情况。

## 6. 亮牌规则（暗亮）
> 亮牌对象：猪♠Q、羊♦J、变压器♣10、红桃A♥A；支持主动亮、自动亮。
> 亮牌阶段：每副牌发牌完成后，独立限时阶段；亮牌选择对其他玩家保密，阶段结束统一揭晓。

### 6.1 自动亮（配置开关 autoLightLastOne，一期默认关闭，可配置）
当 autoLightLastOne 开启：手牌只剩该关键牌时自动亮；关闭则仅玩家手动选择亮。
> 待确认项：autoLightLastOne 一期是否开启，见文末待决策清单。

### 6.2 暗亮保密约束（接口+客户端强制校验）
- 亮牌进行中：**服务端禁止向任何客户端返回任何人的亮牌选择**
- 亮牌阶段结束后：一次性下发全部4人亮牌结果，所有人可见
- AI 在亮牌阶段，同样无法读取其他玩家的亮牌选择，只能操作自己手牌

### 6.3 亮牌首轮限制规则【修订、消除歧义版】
> 核心前提：**每一副牌独立统计各个花色的首次领出墩，限制只在本副生效，不跨副**
> 限制对象：本副已经被亮出的4张关键牌（猪、羊、变压器、红桃A）
> 某花色本副第一次领出形成的墩，适用如下规则：
> 1. 该受限制亮牌，**不允许主动领出这个花色**
> 2. 跟牌场景：如果玩家手里有该花色其他牌，则**禁止跟出这张亮过的关键牌**
> 3. 跟牌兜底：玩家手中该花色仅剩这一张受限制亮牌，无其他同花色，**必须跟出这张亮牌**
> 4. 领出死锁兜底：轮到玩家领出，其所有合法可领出牌全部是受限制亮牌，没有其他牌可选 → 允许领出该亮牌，本次领出解除该限制，避免卡死
>
> 示例：本副红桃首次墩，你手里有♥3、亮过的♥A；你有其他红桃，不能跟♥A；只有♥A一张红桃，则必须跟♥A。

### 6.4 四张全亮定义
四张全亮：**本副亮牌阶段结束时，猪、羊、变压器、红桃A四张全部被亮出（手动/自动亮均可，不限是谁亮）**；打牌过程中不能新增亮牌，跨副不累计四张全亮。
> 待确认：四张全亮是否附加特殊效果，见文末待决策清单。

## 7. 出牌、跟牌、收墩规则
1. 领出人选定领出牌，确定本墩主花色；其余玩家按顺序跟牌。
2. 跟牌优先同花色；有同花色必须跟同花色；无同花色可以垫任意其他花色（垫牌不能赢墩）。
3. 同花色内牌点大者赢墩；赢墩玩家收集本墩所有分牌，并获得下一墩领出权。
4. 每副固定13墩；13墩全部打完，进入常规副牌结算。
5. 出牌/领出超时策略：见第12章异常策略。

## 8. 分牌、计分、特殊牌型规则
> 优先级排序（从高到低）：**满贯 > 窝猪 > 全红 > 变压器倍率 > 基础分**
> 一旦触发满贯，直接走满贯分支，跳过窝猪、全红、变压器、基础分全部计算。

### 8.1 窝猪
条件：玩家本副收墩拿到猪♠Q，且猪是被玩家自己亮出的（手动亮 / 自动亮）。
分值：窝猪 = -400
> 玩家亮的猪自己的同伴得则不算窝猪。

### 8.2 全红
条件：**单个玩家本副收墩集齐全部13张红桃牌**。判定仅看收墩红桃集合，与♥A是否亮、是否在自己手里无关。
分值：全红 = +200
> 全红和窝猪可以同时触发，按顺序叠加。

### 8.3 变压器（♣10）
1. 玩家收墩拿到变压器才生效。
2. 分支判定：
   - 分支1：拿到变压器，并且除变压器以外存在非零个人分 → 个人基础总分 ×2；四张全亮时 ×4
   - 分支2：**仅拿到变压器，没有任何其他分牌 → +50（普通） / 四张全亮 +100**
   - 边界补充：拿到变压器，但其余分牌结算后个人非零总和 = 0（例：窝猪-400 +亮♥A全红+400=0）→ 倍率后结果依旧为0，不触发+50/+100奖励
3. 变压器在满贯触发时无效。

### 8.4 满贯【重大修订，修正手牌数量矛盾】
> 满贯条件：**同一个玩家，在本副牌收墩获得的分牌集合中，同时包含 ♠Q猪、♦J羊、♣10变压器、全部13张红桃牌**。
> ✅ 重点：是【收墩收集到的分牌】，不是发到手的手牌；允许多墩逐步收齐，不是开局手牌集齐。
> 满贯效果：
> 1. 本副直接终止，不再打完剩余墩，跳过窝猪、全红、变压器、常规计分
> 2. 满贯不产生窝猪标记

### 8.5 个人分计算顺序（固定）
1. 检查是否满贯：命中 → 直接满贯分支，终止本副结算
2. 判定窝猪，计入个人分
3. 判定全红，计入个人分
4. 汇总除变压器外的个人所有分，得到原始个人分
5. 判断是否拿到变压器，应用变压器倍率规则（含四张全亮倍率）
6. 输出该玩家本副最终个人分
7. 同队两人个人分相加 = 本副团队原始和，累加入本局累计团队分

## 9. 猪头判定与胜负规则（修订歧义：猪头累加语义）
> 猪头：标记在队伍上；猪头在【本局内持续累加；新局开始猪头清零】
> 判定时机：一副牌常规结算完成后（非满贯副）
> 阈值：团队本局累计分 ≥ +1000 或 ≤ -1000
> 判定表：
| 条件 | 结果 |
|---|---|
| A队≥+1000 且 B队＜±1000 | B队 +1 猪头（A给B画1头） |
| B队≥+1000 且 A队＜±1000 | A队 +1 猪头（B给A画1头） |
| A队≤-1000 且 B队＜±1000 | A队 +1 猪头（B给A画1头） |
| B队≤-1000 且 A队＜±1000 | B队 +1 猪头（A给B画1头） |
| A队≥+1000 且 B队≥+1000 | A队+2，B队+2（互相各被对方画2头） |
| A队≤-1000 且 B队≤-1000 | A队+1，B队+1（互相各被对方画1头） |
> 说明：不存在同一队伍同时≥+1000且≤-1000的数学场景，该分支仅文档兜底，不会触发。

> 本局终止条件：任意队伍猪头达到约定上限，或者本副触发满贯。

## 10. 赛制规则
### 10.1 5局制
一共最多5局；先赢到指定胜局数队伍赢盘；5局打平进入加赛。
> 待确认：加赛规则（加赛局数、是否突然死亡、猪头是否清零），见文末清单。

### 10.2 固定8局制
一共固定8局，打完8局结算盘胜负：
1. 8局打完，统计两队总猪头数量，猪头更少的队伍赢盘。
2. 总猪头相同：看最后一局判定胜负。
    - 最后一局触发满贯：满贯方胜
    - 最后一局阈值画头：被画猪头的一方负
    - 最后一局双方互相画猪头（双方都新增猪头）：【待确认分支】
    - 最后一局双方新增猪头相等：【待确认分支】

## 11. AI 约束与可见信息规范（补充明确公开/私有信息）
### ✅ AI 允许读取（公开信息，客户端同样可见）
1. 所有已经打出的卡牌、每墩出牌记录
2. 每个座位剩余手牌张数
3. 亮牌阶段结束揭晓后的全部亮牌结果
4. 两队本局累计团队分、当前猪头计数
5. 座位身份、队伍归属

### ❌ AI 禁止读取（私有信息）
1. 其他玩家未打出的手牌
2. 亮牌阶段尚未揭晓时，任何人的亮牌选择

### AI 行为约束
- AI 只能操作自己手牌；不能偷看、预判未公开信息；一期AI仅实现基础合规出牌策略，不做高级读牌欺骗。

## 12. 超时、断线、托管异常策略（一期最小可用）
> 一期策略，满足上线基础可用，不做复杂重连回溯
1. **亮牌阶段超时**：超时未选择亮牌 → 等同于不亮任何牌。
2. **领出/跟牌出牌超时**：超时后座位自动托管，由AI接管该座位，继续对局；托管持续到本局结束，不切回真人。
3. **真人玩家断线、主动退出座位**：直接转为AI托管，本局继续跑完，不终止整局。
4. 托管后，该座位计分、猪头归属不变，仍然属于原队伍。

## 14. 验收测试要点（增补评审缺失场景）
> 可直接转化为测试用例
1. 满贯：同一玩家收墩集齐猪、羊、变压器、全部红桃，本局直接结束，不计算窝猪/猪头；验证手牌集齐场景**不能判定满贯**（重点校验）
2. 亮牌首轮限制全分支：
   - 花色首墩，有其他同花色，禁止跟亮牌
   - 花色首墩，仅剩该亮牌，强制跟出
   - 领出时全部可选牌都是受限亮牌，兜底允许领出，不死锁
3. 变压器组合校验：变压器+总分归零，倍率后保持0，不触发+50；仅变压器单独拿分+50；四张全亮倍率×4
4. 窝猪 + 全红叠加计分
5. 猪头双向互画场景：双方≥+1000各+2猪头；双方≤-1000各+1猪头
6. 亮牌保密：亮牌进行中，接口不能透出亮牌选择；结束统一揭晓
7. AI信息隔离：AI不能读取别人手牌、未揭晓亮牌
8. 超时逻辑：亮牌超时=不亮；出牌超时=AI托管
9. 领出权继承：无满贯时，上一副拿猪的玩家下一副领出；满贯后新局从♣2开始
10. 13墩打完才进入常规结算；满贯提前终止副牌

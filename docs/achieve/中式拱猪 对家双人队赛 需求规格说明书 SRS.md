# 中式拱猪【对家双人队赛】需求规格说明书（SRS）

**版本**：V1.0（第一阶段）  
**适用范围**：4人2v2对家赛，固定南北一队 vs 东西一队；任意座位可为真人或AI。  
**不适用范围**：单人赛、自由组队赛、个人积分赛、合满贯。  
**文档性质**：基于已确认对话整理，作为第一阶段开发、测试、验收基线。标注“待确认”的条目需产品最终冻结。

---

## 1. 项目目标

开发一款4人2v2中式拱猪对家赛。游戏以“局”为画猪头段，每局内可连续打多副牌，小分累计用于判定画猪头条件；每达到画猪头条件，本局结束，负方被画相应数量猪头，双方小分清零，进入下一局。最终在规定局数内比较双方累计猪头数，猪头少者获胜。

核心差异：
- 只做南北 vs 东西固定对家赛，不做个人赛。
- 小分不是最终胜负依据，只用于触发画猪头和决定画几头。
- 满贯为个人事件，但触发后本队立即赢下本局，给对方画猪头。
- 支持暗亮：亮牌阶段结束前，其他方只能看到已亮牌背/数量，不能看到具体牌。

---

## 2. 术语定义

| 术语 | 定义 |
|---|---|
| 副牌 | 一次发牌→亮牌→出牌→结算的完整过程 |
| 局 | 画猪头段。从0分开始，可包含多副牌，直到某副牌结算后触发画猪头或满贯；画头后本局结束，小分清零 |
| 盘/场 | 由固定局数组成，如5局制、8局制；最终比较双方猪头总数 |
| 小分 | 每副牌个人/团队计分，仅用于判定画猪头条件，不直接决定最终胜负 |
| 猪头 | 本局负方被记录的惩罚标记；最终猪头少者胜 |
| 窝猪 | 亮猪者本人最终自己收下♠Q，猪分记-400 |
| 满贯 | 单个玩家集齐猪、羊、变压器、全部13张红桃；触发后本队立即赢下本局 |
| 全亮 | 本局四张关键牌均被亮出（含自动亮），不论谁亮；待最终确认 |
| 暗亮 | 亮牌提交阶段互相不可见具体牌，亮牌阶段结束后统一公开 |
| 差值分 | 可选计分模式，第一阶段不采用；第一阶段固定团队原始和累计 |

---

## 3. 用户角色与座位

1. 固定4个座位：南、北、东、西。
2. 队伍固定：南+北为一队；东+西为一队。
3. 任意座位可为真人或AI机器人，支持真人+真人、真人+AI、AI+AI混合。
4. 出牌顺序为逆时针，默认座位顺序：南→东→北→西（以实际座位数组为准）。
5. 第一阶段不提供单打模式、不提供自由换座组队。

---

## 4. 总体游戏流程

```
创建对局（选择赛制、座位真人/AI）
→ 新局开始，双方小分清零
→ 发牌（每人13张）
→ 亮牌阶段（暗亮提交）
→ 亮牌揭晓（统一公开正面）
→ 出牌阶段（逐墩）
→ 副牌结算
   ├─ 满贯判定：触发则本队赢下本局，给对方画1或2头，本局结束
   ├─ 普通计分：个人分→团队小分累计
   ├─ 画猪头判定：达到条件则画头，本局结束
   └─ 未触发：继续下一副牌，小分继续累计
→ 本局结束：记录猪头，小分清零
→ 判断赛制是否结束
   ├─ 未结束：进入下一局
   └─ 结束：统计双方总猪头，少者胜；同猪头按赛制规则裁决
```

## 5. 发牌与领出规则

1. 一副牌52张，无大小王，每人13张。
2. 每局第一副牌：持有♣2的玩家领出，且首引必须出♣2。
3. 局内后续副牌：上一副牌拿到猪（♠Q）的玩家领出，领出花色不限。
4. 若上一副因满贯结束，本局随即结束，不进入下一副；新局第一副重新按♣2规则。
5. 画猪头后本局结束，新局第一副重新按♣2规则。

---

## 6. 亮牌规则

### 6.1 可亮牌
♠Q猪、♦J羊、♣10变压器、♥A红桃A。

### 6.2 亮牌阶段
1. 发牌后进入亮牌阶段，玩家自主选择亮/不亮。
2. **暗亮**：亮牌阶段未结束时，自己可见自己亮牌正面；其他方只能看到“已亮牌背/数量”，不能看到具体牌种和位置。
3. 亮牌阶段结束后，统一公开所有亮牌正面，之后所有人可见。
4. 提交后不可撤回；超时未提交视为不亮。
5. 自动亮：四张可亮牌已亮3张时，剩余1张是否自动亮由配置 `autoLightLastOne` 控制；若开启，由服务端在亮牌截止时判定，揭晓时公开。第一阶段默认值待确认。
6. 第一阶段固定为“揭晓后公开正面”，暂不开发“出牌阶段仍隐藏具体亮牌”的扩展模式。

### 6.3 亮牌首轮限制
1. 本局某花色第一次出现的一墩，该花色中被亮过的牌**不能领出，也不能跟牌**。
2. 例外：若玩家手中该花色仅剩这一张亮牌，跟牌时必须出；但**不允许主动领出该花色**。
3. 若轮到领出且手中仅剩受限制亮牌、无其他合法领出牌，需兜底允许领出该亮牌，避免死锁（待确认兜底细则）。
4. 该限制对亮猪、亮羊、亮变、亮♥A一致适用。
5. 亮牌是个人行为，只影响拿牌者计分；满贯画猪头为团队结果，属于例外。

---

## 7. 出牌与收墩规则

1. 一墩：领出一家出一张，逆时针依次跟牌，4张为一墩。
2. 强制跟牌：有领出花色必须跟同花色；没有该花色可任意垫其他花色，垫牌视为本墩最小。
3. 同花色点数最大者赢墩；无将牌，不同花色不比较大小。
4. 赢墩者收下本墩所有分牌，并获得下一墩领出权。
5. 一墩分牌归赢墩个人，结算时先算个人分，再相加为团队小分。
6. 牌大小：A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3 > 2。

---

## 8. 计分规则

### 8.1 基础分值
| 牌 | 名称 | 基础分 | 亮牌后 |
|---|---|---|---|
| ♠Q | 猪 | -100 | -200 |
| ♦J | 羊 | +100 | +200 |
| ♣10 | 变压器 | 特殊倍率 | 倍率升级 |
| ♥A | 红桃A | -50 | 红桃分值×2 |
| ♥K | 红桃K | -40 | 受♥A亮牌倍率 |
| ♥Q | 红桃Q | -30 | 受♥A亮牌倍率 |
| ♥J | 红桃J | -20 | 受♥A亮牌倍率 |
| ♥10~♥5 | 红桃10~5 | 各-10 | 受♥A亮牌倍率 |
| ♥4~♥2 | 红桃4~2 | 0 | 0 |

全部红桃原始总分：-200。

### 8.2 变压器规则
1. 玩家拿到♣10且同时拿到任意非零分牌：该玩家本局所有非零分总和×2；若亮变压器则×4。
2. 玩家只拿到变压器、无任何其他非零分牌：基础+50；亮变压器后+100。
3. 变压器放大的是“拿到它的那个玩家”的个人分，不直接放大团队分。

### 8.3 全红规则
1. 单个玩家收集全部13张红桃：红桃总分从-200反转为+200；若♥A亮牌则+400。
2. 全红只反转红桃分数，猪分照常计算；若同时窝猪，按窝猪规则叠加。
3. 全红为个人事件，不支持两人合全红。

### 8.4 窝猪规则
1. 仅当**亮猪者本人最终自己收下♠Q**时触发窝猪，猪分记-400。
2. 亮猪后被同伴收下，不算窝猪；同伴按亮猪后的-200计猪分。
3. 自动亮的猪若本人自收，默认算窝猪（待确认）。
4. 窝猪与全红同时发生：先算全红红桃反转分，再叠加窝猪-400。  
   - 例：窝猪+全红 = -400 + 200 = -200；若亮♥A则 -400 + 400 = 0。
5. 窝猪后若该玩家拿变压器且亮变，对最终个人非零总分应用×4。  
   - 例：窝猪-400且亮变 → -1600；窝猪+全红=-200且亮变 → -800；窝猪+亮♥A全红=0且亮变 → 0。
6. 满贯触发时，不触发窝猪，不计算猪负分。

### 8.5 满贯规则
1. 满贯条件：单个玩家集齐猪、羊、变压器、全部13张红桃。必须个人拿齐，不支持合满贯。
2. 满贯优先级最高：触发后**本队立即赢下本局**，不结算普通小分，不触发窝猪，不再检查小分阈值。
3. 满贯给对方画猪头：
   - 非全亮：对方画1头。
   - 四张全亮：对方画2头。
4. “四张全亮”默认定义：本局四张关键牌均被亮出（含自动亮），不论谁亮。待产品最终确认。
5. 满贯时满贯者自己得猪也不计负分；普通分牌仅可做展示/复盘，不参与本局小分和画头判定。
6. 满贯本局结束后，双方小分清零，进入下一局。

### 8.6 个人分计算顺序
1. 统计四名玩家各自收下的分牌。
2. 先判满贯：若触发，进入满贯分支，本队赢下本局，结束本副结算。
3. 未满贯则判全红。
4. 应用亮牌修正：亮猪、亮羊、亮♥A。
5. 处理窝猪：亮猪者自收猪最终-400，替代亮猪-200。
6. 处理变压器倍率：对该玩家最终非零分总和×2或×4；仅变压器无其他非零分则+50/+100。
7. 得到个人本副原始分。
8. 团队本副小分 = 南分+北分，或东分+西分；第一阶段固定团队原始和累计，不使用差值分。
9. 将团队本副小分累加到本局团队小分。

## 9. 画猪头与本局胜负

### 9.1 普通画猪头条件
每副牌结算后、未触发满贯时，检查本局团队累计小分：

| 条件 | 画头结果 | 本局结果 |
|---|---|---|
| 仅A队累计≤-1000 | A队画1头 | B队赢下本局 |
| 仅A队累计≥+1000 | B队画2头 | A队赢下本局 |
| A队≤-1000且B队≥+1000 | A队画3头 | B队赢下本局 |
| A队≥+1000且B队≥+1000 | 双方各被对方画2头 | 本局新增猪头少者为本局胜者；相同则待确认 |
| A队≤-1000且B队≤-1000 | 双方各被对方画1头 | 本局新增猪头少者为本局胜者；相同则待确认 |
| 双方同时分别满足正/负阈值 | 按各自触发条件分别画头；同一队同时满足两条按3头计 | 按新增猪头少者判本局胜者；相同则待确认 |

说明：
- “本队获胜”在本局语境指赢下本局并给对方画头，不是最终整盘胜利。
- 第一阶段采用团队原始和累计，可能出现双方同时达标，按上表处理。
- 若产品希望简化，可后续改为团队差值分累计，但第一阶段不采用。

### 9.2 满贯画头
满贯优先于普通阈值：触发满贯即本队赢下本局，给对方画1头（非全亮）或2头（四张全亮），不再检查普通阈值。

### 9.3 画头后处理
1. 本局立即结束。
2. 记录双方本局新增猪头数，累加到本盘总猪头。
3. 双方本局小分清零。
4. 进入下一局；新局第一副由持♣2者领出且必须出♣2。

## 10. 赛制与最终胜负

### 10.1 局与副牌关系
1. 一局可包含多副牌，直到画猪头或满贯触发。
2. 局内未画头时，小分继续累计；下一副仍由上一副拿猪者领出。
3. 画头后本局结束，小分清零，进入下一局。

### 10.2 5局制
1. 固定进行5局，累计双方总猪头数。
2. 5局后猪头总数少者获胜。
3. 若5局后双方总猪头数相同，则加赛，直至分出胜负。加赛局数规则待确认。

### 10.3 固定8局制
1. 固定进行8局，累计双方总猪头数。
2. 8局后猪头总数少者获胜。
3. 若8局后双方总猪头数相同，则判最后一局输者负。  
   “最后一局输者”默认定义：最后一局新增猪头多者为本局输者；若最后一局双方新增猪头相同，按该局结束方式判定（满贯方胜；阈值触发时被画头方负）。待产品最终确认。

### 10.4 本局胜负用途
本局胜负主要用于：
- 记录本局谁赢；
- 固定8局同猪头时判定最后一局输者；
- 展示与战绩。
最终胜负仍以总猪头数少者为准。

## 11. AI与信号系统范围

1. 第一阶段座位支持真人/AI混合，AI必须只能读取公开信息，不得读取未公开手牌和未揭晓亮牌。
2. AI需支持合法出牌、基本跟牌/垫牌、基础计分规避。
3. 高级AI亮牌策略、关键牌概率推断、搭档信号解读可作为后续阶段；第一阶段是否包含基础信号提示待确认。
4. 若第一阶段不做信号系统，则UI不展示信号解读，AI不依赖信号。

## 13. 待确认问题清单

1. 满贯“四张全亮”是否确认为本局四张关键牌均亮（含自动亮），不论谁亮。
2. `autoLightLastOne` 第一阶段默认开启还是关闭。
3. 普通画猪头中，双方同时达标且新增猪头相同时，本局胜者如何判定。
4. 固定8局总猪头相同，“最后一局输者”的精确判定，尤其最后一局双方新增猪头相同的情况。
5. 5局制相同后加赛的具体规则：加赛几局、是否突然死亡、加赛是否清零猪头。
6. 领出时手中仅剩受限制亮牌且无其他合法领出牌的兜底规则。
7. 第一阶段是否包含搭档信号提示和高级AI概率推断。
8. 自动亮猪自收是否算窝猪（建议算）。

## 14. 验收要点

1. 暗亮阶段其他方无法通过接口/UI看到具体亮牌。
2. 亮牌首轮限制正确：不能领出、不能跟牌，唯一亮牌跟牌必须出、不能主动领出。
3. 窝猪仅亮猪者自收触发，-400；被同伴收按-200。
4. 窝猪+全红+亮♥A=0；窝猪+亮变=-1600；组合顺序正确。
5. 满贯立即结束本局，不结算普通小分，不触发窝猪，给对方画1或2头。
6. 普通画猪头表正确，画头后小分清零。
7. 局内未画头可多副累计，下一副由上一副拿猪者领出。
8. 5局制/8局制最终猪头比较和同猪头裁决正确。
9. 任意座位真人/AI混合可正常对局。
10. 第一阶段无单打、无自由组队入口。

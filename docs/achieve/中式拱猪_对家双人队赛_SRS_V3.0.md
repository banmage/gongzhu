# 中式拱猪【对家双人队赛】需求规格说明书（SRS）

**版本**：V3.0  
**修订基线**：V2.0  
**适用范围**：4人2v2对家赛，固定南北一队 vs 东西一队；任意座位可为真人或AI。  
**不适用范围**：单人赛、自由组队赛、个人积分赛、合满贯、出牌阶段隐藏亮牌模式、差值分模式。  
**文档性质**：V3.0 已按产品澄清与评审意见修订，消解 V2.0 中计分方向、变压器独拿、全亮作用域、自动亮时点、首轮限制、加赛/回溯等歧义。临时默认项标注⚠️，可直接进入开发，产品最终冻结时可回滚。

---

## 修订说明（V2.0 → V3.0）

1. **明确正分阈值方向**：某队小分达到 +1000（或更高，如 +2000）时，是**对方被画猪头**，本队赢下本局；负分阈值才是本队被画头。6.2 表与 7.4 已改写，避免“正分高给自己画头”的误读。
2. **重写变压器独拿规则**：只有实际收牌中除♣10外**没有任何其他计分牌**，才计 +50；亮变 +100。若除♣10外还有任意计分牌（猪、羊、任意数量红桃，含♥4~♥2），均先累加修正后分值，再对非零总分×2；亮变×4。修正后总分为0时仍为0，不触发 +50/+100。
3. **全亮作用域改为“本副牌”**：满贯画1/2头依据触发满贯的该副牌四张关键牌是否全亮，不再写“本局”。
4. **明确自动亮时点**：全员提交或亮牌截止后，先执行 `autoLightLastOne` 判定，再立即揭晓；自动亮在揭晓时公开，不与手动亮牌提前展示。
5. **固定计分流水线顺序**：统计收牌 → 满贯判定 → 亮牌修正（亮猪/亮羊/亮♥A红桃翻倍）→ 全红反转 → 窝猪 → 变压器倍率/独拿 → 个人分 → 团队小分。
6. **修正首轮限制**：限制对象是“受限制的亮牌”，不是整个花色；允许领出同花色非亮牌；“某花色第一次出现”定义为“本副该花色首次作为领出花色的一墩”。
7. **修正加赛与8局同猪头裁决**：加赛突然死亡只看总猪头；6.4 仅用于记录本局胜负；8局同猪头先按最后一局新增猪头，再按6.4，再回溯。
8. **明确定义“计分牌”**：♠Q、♦J、全部13张红桃（含♥4~♥2）均为计分牌，用于变压器独拿判定与超时垫牌“非计分牌优先”。
9. **补充窝猪被对手收下**：非亮猪者收下♠Q，无论同伴还是对手，均按亮猪后 -200；仅亮猪者本人自收才 -400。
10. **补充6.5兜底胜负**、**断线立即AI代打**、**满贯后小分处理**、**数据模型字段**、**验收用例**。

## 1. 概述

### 1.1 项目目标

开发一款4人2v2中式拱猪对家赛。游戏以“局”为画猪头段：每局内可连续打多副牌，小分累计用于判定画猪头条件；每达到画猪头条件，本局结束，负方被画相应数量猪头，双方小分清零，进入下一局。最终在规定局数内比较双方累计猪头数，猪头少者获胜。

核心设计：
- 只做南北 vs 东西固定对家赛，不做个人赛。
- 小分不是最终胜负依据，只用于触发画猪头和决定画几头。
- 满贯为个人事件，但触发后本队立即赢下本局，给对方画猪头。
- 支持暗亮：亮牌阶段结束前，其他方只能看到“已亮牌背/数量”，不能看到具体牌。

### 1.2 术语定义

| 术语 | 定义 |
|---|---|
| 盘 | 整场对赛，由固定局数组成（5局制/8局制）；最终比较双方猪头总数 |
| 局 | 画猪头段。从0分开始，可包含多副牌，直到某副牌结算后触发画猪头或满贯；画头后本局结束，小分清零 |
| 副牌 | 一次发牌→亮牌→出牌→结算的完整过程 |
| 小分 | 每副牌个人/团队计分，仅用于判定画猪头条件，不直接决定最终胜负 |
| 猪头 | 本局负方被记录的惩罚标记；盘终猪头少者胜 |
| 窝猪 | 亮猪者本人最终自己收下♠Q，猪分记-400 |
| 满贯 | 单个玩家集齐猪、羊、变压器、全部13张红桃；触发后本队立即赢下本局 |
| 全亮 | **本副牌**四张关键牌均被亮出（含自动亮），不论谁亮 |
| 暗亮 | 亮牌提交阶段互相不可见具体牌，亮牌阶段结束后统一公开 |
| 计分牌 | ♠Q、♦J、♣10、全部13张红桃（含♥4~♥2）。♣10为变压器本身，在独拿判定中作为“变压器”，不计入“其他计分牌” |
| 独拿变压器 | 玩家实际收牌中除♣10外没有任何其他计分牌；普通黑桃/方块/梅花非关键牌不影响独拿 |
| 首轮限制花色 | 本副牌中某花色首次作为领出花色的一墩 |
| 差值分 | 可选计分模式，V3.0 不采用；固定团队原始和累计 |

## 2. 用户角色与座位

1. 固定4个座位：南、北、东、西。出牌顺序为逆时针：南→东→北→西。
2. 队伍固定：南+北为一队（下称 A 队）；东+西为一队（下称 B 队）。
3. 任意座位可为真人或 AI 机器人，支持真人+真人、真人+AI、AI+AI 混合。
4. V3.0 不提供单打模式、不提供自由换座组队。

---

## 3. 总体游戏流程

```
创建对局（选择赛制、座位真人/AI）
→ 盘开始
   └─ 新局开始，双方小分清零
      → 发牌（每人13张）
      → 亮牌阶段（暗亮提交，全员提交后先执行自动亮判定，再提前揭晓）
      → 亮牌揭晓（统一公开正面）
      → 出牌阶段（13墩）
      → 副牌结算
         ├─ 满贯判定（结算时判定）：触发则本队赢下本局，给对方画1或2头
         ├─ 普通计分：个人分→团队小分累计
         ├─ 画猪头判定：达到条件则画头，本局结束
         └─ 未触发：继续下一副牌，小分继续累计
      → 本局结束：记录猪头，小分清零
      → 判断赛制是否结束：未结束则进入下一局
→ 盘结束：统计双方总猪头，少者胜；同猪头按赛制规则裁决
```

## 4. 对局规则

### 4.1 发牌与领出

1. 一副牌52张，无大小王，随机洗牌后每人13张。
2. 每局第一副牌：持有♣2的玩家领出，且首引必须出♣2。
3. 局内后续副牌：上一副牌拿到猪（♠Q）的玩家领出，领出花色不限。
4. 若上一副因满贯结束，本局随即结束，不进入下一副；新局第一副重新按♣2规则。
5. 画猪头后本局结束，新局第一副重新按♣2规则。

### 4.2 亮牌规则

#### 4.2.1 可亮牌
♠Q猪、♦J羊、♣10变压器、♥A红桃A。

#### 4.2.2 亮牌阶段
1. 发牌后进入亮牌阶段，玩家自主选择亮/不亮，允许一名玩家同时亮多张关键牌。
2. **暗亮**：亮牌阶段未结束时，自己可见自己亮牌正面；其他方只能看到“已提交亮牌数量/牌背”，不能看到具体牌种。
3. 亮牌阶段结束后，统一公开所有亮牌正面，之后所有人可见。
4. 提交后不可撤回；超时未提交视为不亮；全部4家提交后立即进入揭晓。
5. 自动亮：四张可亮牌已亮3张时，若配置 `autoLightLastOne` 开启（V3.0 默认开启⚠️），由服务端在**全员提交后或亮牌截止时**判定剩余1张自动亮，判定后立即揭晓并公开。
6. 固定为“揭晓后公开正面”，不做“出牌阶段仍隐藏具体亮牌”的扩展模式。
7. 自动亮的牌与其他亮牌同等适用 4.2.4 首轮限制；自动亮在揭晓时公开，未揭晓前不计入“已亮N张”展示。

#### 4.2.3 亮牌对计分的影响
亮牌是个人行为，只影响拿牌者计分；满贯画猪头为团队结果，属于例外（见 5.6）。

#### 4.2.4 亮牌首轮限制
1. **每副牌**中，某花色第一次作为领出花色的一墩，该花色中**被亮过的牌**不能领出，也不能跟牌。
2. 例外①（跟牌）：若玩家手中该花色仅剩这一张受限制亮牌，跟牌时必须出。
3. 例外②（领出）：玩家不允许主动领出受限制亮牌；允许领出同花色非亮牌。若轮到领出且手中只剩受限制亮牌、无其他合法领出牌，兜底允许任选一张受限制亮牌领出，避免死锁（V3.0 默认⚠️，UI 需提示）。
4. 该限制对亮猪、亮羊、亮变、亮♥A一致适用；自动亮的牌同样适用。
5. 若某花色此前仅被垫牌、未被作为领出花色，不消耗该花色首轮限制。

### 4.3 出牌与收墩

1. 一墩：领出一家出一张，逆时针依次跟牌，4张为一墩，共13墩。
2. 强制跟牌：有领出花色必须跟同花色；没有该花色可任意垫其他花色，垫牌视为本墩最小。
3. 同花色点数最大者赢墩；无将牌，不同花色不比较大小。
4. 赢墩者收下本墩所有分牌，并获得下一墩领出权。
5. 一墩分牌归赢墩个人，结算时先算个人分，再相加为团队小分。
6. 牌大小：A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3 > 2。

## 5. 计分规则

### 5.1 基础分值

| 牌 | 名称 | 基础分 | 亮牌后 |
|---|---|---|---|
| ♠Q | 猪 | -100 | -200 |
| ♦J | 羊 | +100 | +200 |
| ♣10 | 变压器 | 特殊倍率 | 倍率升级（×2→×4） |
| ♥A | 红桃A | -50 | -100（即红桃分值×2，含♥A自身） |
| ♥K | 红桃K | -40 | -80 |
| ♥Q | 红桃Q | -30 | -60 |
| ♥J | 红桃J | -20 | -40 |
| ♥10~♥5 | 红桃10~5 | 各-10 | 各-20 |
| ♥4~♥2 | 红桃4~2 | 0 | 0 |

全部红桃原始总分：-200。♥4~♥2虽为0分，仍属于“计分牌/红桃牌”，用于变压器独拿判定与超时垫牌“非计分牌优先”。

### 5.2 个人分计算顺序

固定顺序如下，不得调换：

1. 统计四名玩家各自收下的分牌。
2. 判满贯：若触发，进入满贯分支（5.6），本队赢下本局，本副不再进行普通计分。
3. 应用亮牌修正：亮猪按 -200、亮羊按 +200；亮♥A使该玩家红桃分值×2（含♥A自身）。亮变不在此步处理。
4. 判全红（5.4）：在亮♥A翻倍之后反转红桃总分。
5. 处理窝猪（5.5）：亮猪者自收♠Q时猪分直接记 -400，替代亮猪 -200；非亮猪者收♠Q按亮猪后 -200 或未亮猪 -100。
6. 处理变压器倍率（5.3）：独拿则 +50/+100；非独拿则对修正后非零总分×2/×4。
7. 得到个人本副原始分。
8. 团队本副小分 = 南分+北分（A队），或东分+西分（B队）；固定团队原始和累计。
9. 将团队本副小分累加到本局团队小分。

### 5.3 变压器规则

1. **独拿变压器**：玩家实际收牌中，除♣10外没有任何其他计分牌（♠Q、♦J、任意数量红桃，含♥4~♥2），则基础 +50；亮变压器后 +100。普通黑桃/方块/梅花非关键牌不影响独拿。
2. **非独拿变压器**：玩家实际收牌中除♣10外还有任意计分牌（包括猪、羊、任意数量红桃，含0分红桃），则不适用 +50/+100；先按 5.2 顺序累加该玩家修正后总分（含猪、羊、红桃、全红、窝猪等），再对该非零总分×2；亮变则×4。若修正后总分为0，则×2/×4仍为0，不触发 +50/+100。
3. 变压器放大的是“拿到它的那个玩家”的个人分，不直接放大团队分。
4. 示例：
   - 仅♣10 + 普通非计分牌：独拿，+50；亮变 +100。
   - ♣10 + ♥4（0分红桃）：非独拿，修正后总分0，×2/×4仍0，不+50。
   - 窝猪 -400 且亮变：有猪，非独拿，×4 = -1600。
   - 窝猪+全红+亮♥A = 0，且亮变：非独拿，×4仍0。

### 5.4 全红规则

1. 单个玩家收集全部13张红桃：红桃总分从 -200 反转为 +200；若♥A亮牌，先翻倍至 -400 再反转为 +400。
2. 全红只反转红桃分数，猪分照常计算；若同时窝猪，按 5.5 叠加。
3. 全红为个人事件，不支持两人合全红。

### 5.5 窝猪规则

1. 仅当**亮猪者本人最终自己收下♠Q**时触发窝猪，猪分直接记 -400，不再按亮猪 -200 计算。
2. 非亮猪者收下♠Q：无论同伴还是对手，均按亮猪后 -200 计猪分；若猪未亮，收者按 -100。
3. 自动亮的猪若本人自收，算窝猪（V3.0 默认⚠️）。
4. 窝猪与全红同时发生：先算全红红桃反转分，再叠加窝猪 -400。
   - 窝猪+全红 = -400 + 200 = -200；亮♥A则 -400 + 400 = 0。
5. 窝猪后若该玩家拿变压器且亮变，按 5.3 非独拿处理：对最终个人非零总分应用×4。
   - 窝猪-400且亮变 → -1600；窝猪+全红=-200且亮变 → -800；窝猪+亮♥A全红=0且亮变 → 0（×4仍0，不触发 +50/+100）。
6. 满贯触发时，不触发窝猪，不计算猪负分。

### 5.6 满贯规则

1. 满贯条件：单个玩家集齐猪、羊、变压器、全部13张红桃。必须个人拿齐，不支持合满贯。
2. 满贯一律在**整副牌结算时**判定，不做墩内中断。
3. 满贯优先级最高：触发后本队立即赢下本局，不结算普通小分，不触发窝猪，不再检查小分阈值。
4. 满贯给对方画猪头：
   - 非全亮：对方画1头。
   - 四张全亮：对方画2头。
5. “四张全亮”定义：**触发满贯的该副牌**四张关键牌均被亮出（含自动亮），不论谁亮。
6. 满贯时满贯者自己得猪也不计负分；普通分牌仅可做展示/复盘，不参与本局小分和画头判定。满贯触发后，本局之前已累计小分不再用于画头，本局结束清零，仅保留展示/复盘数据。
7. 满贯本局结束后，双方小分清零，进入下一局。

## 6. 画猪头判定与一局结束

### 6.1 判定流程

每副牌结算后：
1. 先判满贯（5.6）：触发则按 6.3 处理，结束本局。
2. 未触发满贯，累加团队小分后按 6.2 表判定。
3. 触发画头则本局结束；未触发则继续下一副牌。

### 6.2 普通画猪头条件

设 A 队、B 队本局累计小分为 SA、SB。**画头结果列指“被画头的一方”**。正分阈值是进攻：某队小分达到 +1000 或更高，由对方被画头；负分阈值是防守：某队小分达到 -1000 或更低，本队被画头。

| 触发条件 | 画头结果（被画头方） | 本局胜者 |
|---|---|---|
| 仅 SA ≤ -1000 | A队画1头 | B队 |
| 仅 SA ≥ +1000 | B队画2头 | A队 |
| 仅 SB ≤ -1000 | B队画1头 | A队 |
| 仅 SB ≥ +1000 | A队画2头 | B队 |
| SA ≤ -1000 且 SB ≥ +1000 | A队画3头 | B队 |
| SA ≥ +1000 且 SB ≤ -1000 | B队画3头 | A队 |
| SA ≥ +1000 且 SB ≥ +1000 | 双方各画2头 | 新增猪头少者；相同按 6.4 裁决 |
| SA ≤ -1000 且 SB ≤ -1000 | 双方各画1头 | 新增猪头少者；相同按 6.4 裁决 |

说明：
- 单队不可能同时满足正负两条阈值，无需额外规则。
- 某队小分达到 +1000、+2000 或更高，均按“对方被画2头”处理，不是给自己画头。
- 双方均正高时，双方各自的正高分别使对方画2头，故双方各画2头。
- 双方均负低时，双方各自的负低分别使本队画1头，故双方各画1头。

### 6.3 满贯画头

满贯优先于普通阈值：触发满贯即本队赢下本局，给对方画1头（非全亮）或2头（该副四张全亮），不再检查 6.2 表。

### 6.4 新增猪头相同时的本局裁决（临时默认⚠️）

双方本局新增猪头数相同时，依次比较：
1. 本局双方累计小分，小分更低（更负）的一方为本局负者；
2. 若小分也相同，本局判和局，双方各记本局胜负为平。

### 6.5 一局兜底终止（新增⚠️）

单局设副数上限（默认20副）。达到上限仍未触发画头时：
1. 比较双方本局累计小分，小分更低方被画1头，本局结束；
2. 小分相同则双方各画1头，本局按 6.4 判和局。

### 6.6 画头后处理

1. 本局立即结束。
2. 记录双方本局新增猪头数，累加到本盘总猪头。
3. 双方本局小分清零。
4. 进入下一局；新局第一副由持♣2者领出且必须出♣2。

---

## 7. 赛制与最终胜负

### 7.1 5局制

1. 固定进行5局，累计双方总猪头数。
2. 5局后猪头总数少者获胜。
3. 若5局后双方总猪头数相同，进入加赛（临时默认⚠️）：
   - 加赛采用“突然死亡”：每加赛1局结束后比较**总猪头数**，总猪头少者立即获胜。
   - 若总猪头仍相同，继续加赛，直至分出胜负。
   - 6.4 仅用于记录该加赛局本局胜负，不直接决定加赛胜负。
   - 加赛局产生的猪头正常累计入总猪头。

### 7.2 固定8局制

1. 固定进行8局，累计双方总猪头数。
2. 8局后猪头总数少者获胜。
3. 若8局后双方总猪头数相同，判**最后一局输者负**。最后一局输者定义（V3.0 默认⚠️）：
   1. 最后一局新增猪头多者为本局输者；
   2. 若最后一局双方新增猪头相同，按 6.4 判本局胜负；若 6.4 判出胜负，该局负者为输者；
   3. 若 6.4 判和局，依次向前回溯最近一局有胜负的局，该局负者为输者；
   4. 若整盘无胜负局（极端情况），双方判和。

### 7.3 本局胜负用途

本局胜负用于：记录本局谁赢、固定8局同猪头时回溯裁决、展示与战绩。最终胜负仍以总猪头数少者为准。

### 7.4 计分模式备注

V3.0 固定采用团队**原始和**累计。该模式下：
- 正分（羊、变压器、全红）是进攻性资源：本队正分越高，越会使对方被画猪头。
- 负分（猪、红桃）是防守风险：本队负分越低，本队越会被画猪头。
- 玩家策略上会争抢羊、变压器、全红，同时规避猪和红桃负分，与传统“抢羊抢变”体验一致。
- 差值分模式列为后续可选；若产品需要调整攻防平衡，可再评估。

## 8. 对局过程管理

### 8.1 限时

| 环节 | 时限（默认，可配置） |
|---|---|
| 亮牌阶段 | 30秒 |
| 每墩出牌 | 20秒 |

### 8.2 超时处理

1. 亮牌超时未提交：视为不亮。
2. 出牌超时：由系统自动打出该玩家当前最小合法牌；垫牌时非计分牌优先，再按点数最小；若必须跟牌，同花色最小合法；若受首轮限制，按合法牌选择。对局不中断。
3. 系统代打需在 UI 明确标记，复盘可见。

### 8.3 断线重连

1. 玩家断线后立即由 AI 按 8.2 规则代打并标记（V3.0 默认⚠️）。
2. 断线后保留座位60秒；60秒内重连：恢复正常操作，历史牌局状态全量同步。
3. 超时未归：判为离场，该座位由 AI 永久接管至本盘结束。

### 8.4 真人离场

真人主动退出按 8.3 第3条处理，不可中途换人。

## 9. 信息可见性与AI

### 9.1 信息集（接口级约束）

服务端按阶段下发信息，任何客户端（含 AI）不得获取超出下表的信息：

| 阶段 | 可见信息 |
|---|---|
| 暗亮阶段 | 自己13张手牌、自己亮牌正面、每家已提交亮牌数量（不含尚未判定的自动亮；仅数量与牌背，不含牌种） |
| 亮牌揭晓后 | 所有亮牌正面（含自动亮） |
| 出牌阶段 | 各家剩余牌数、各墩已出牌、历史出牌记录 |
| 结算后 | 各玩家本副分牌明细与个人分 |

暗亮阶段其他方不能通过任何接口获取具体亮牌——此为验收硬约束，不仅限于 UI 隐藏。

### 9.2 AI约束

1. AI 只接收与真人玩家相同的信息集，不得读取未公开手牌、未揭晓亮牌、其他玩家手牌或牌堆剩余牌。
2. AI 需支持合法出牌、基本跟牌/垫牌、基础计分规避。
3. 高级AI亮牌策略、关键牌概率推断、搭档信号解读列为后续阶段。

### 9.3 信号系统

V3.0 不做信号系统：UI 不展示信号解读，AI 不依赖信号。

## 10. 数据模型与状态机

### 10.1 状态机

```
盘(Match) ──包含──> 局(Round) ──包含──> 副(Deal)
副的状态机：
  发牌 → 暗亮 → 揭晓 → 出牌(领出→跟牌×3 → 收墩)×13 → 结算
        ↑__________（未画头）__________|
局结束 → 新局 或 盘结束 → 终局结算
```

### 10.2 核心实体（最小集）

- Match：赛制、局数上限、双方总猪头、状态、`auditSeed`。
- Round：本局双方小分、本局新增猪头、副数计数、状态、`winner/loser/result`。
- Deal：四家手牌、亮牌记录（含自动亮标记）、`allKeyCardsLit`、13墩记录、领出权、结算结果。
- Trick：领出者、四张出牌、赢墩者、分牌归属。
- Player：座位、真人/AI、断线状态、`takeoverMode`。

### 10.3 回放与审计

1. 每副牌记录完整操作序列（含系统代打标记），支持整盘回放。
2. 发牌结果记录随机种子，支持重现与审计。

## 13. 验收要点

1. 暗亮阶段其他方无法通过任何接口获取具体亮牌；自动亮未揭晓前不提前展示。
2. 亮牌首轮限制正确作用于每副牌：受限制亮牌不能领出、不能跟牌；唯一亮牌跟牌必须出；允许领出同花色非亮牌；兜底领出不死锁。
3. 窝猪仅亮猪者自收触发-400；被同伴或对手收按-200；未亮猪收者按-100；自动亮猪自收算窝猪。
4. 数值用例：
   - 窝猪+全红 = -200；窝猪+全红+亮♥A = 0；窝猪+亮变 = -1600；窝猪+全红+亮♥A+亮变 = 0（非独拿×4仍0）。
   - 独拿变压器 +50，亮变 +100；仅♣10+♥4（0分红桃）为非独拿，结果0，不+50。
5. 满贯在结算时判定，立即结束本局，不结算普通小分，不触发窝猪；按**触发满贯的该副牌**四张关键牌是否全亮，给对方画1或2头。
6. 普通画猪头表（6.2）全组合正确：正分高使对方被画头，负分低使本队被画头；含对称组合；画头后小分清零。
7. 局内未画头可多副累计，下一副由上一副拿猪者领出；单局达副数上限按6.5兜底。
8. 5局制/8局制最终猪头比较和同猪头裁决（含加赛、回溯）正确。
9. 超时、断线重连、离场AI接管符合第8章；断线立即AI代打并标记。
10. 任意座位真人/AI混合可正常对局；AI 不超出公开信息集。
11. 无单打、无自由组队入口。
12. 支持整盘回放与发牌种子审计。

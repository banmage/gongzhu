# 中式拱猪【对家双人队赛】需求规格说明书（SRS）

**版本**：V2.0
**修订基线**：V1.0 评审版
**适用范围**：4人2v2对家赛，固定南北一队 vs 东西一队；任意座位可为真人或AI。
**不适用范围**：单人赛、自由组队赛、个人积分赛、合满贯、出牌阶段隐藏亮牌模式、差值分模式。
**文档性质**：V2.0 已按评审意见消解全部内部矛盾，并为原"待确认"条目给出**临时默认裁决**（标注⚠️）。临时默认可直接进入开发，产品最终冻结时可回滚。

---

## 修订说明（V1.0 → V2.0）

1. **修复矛盾①**：变压器"独拿+50/+100"的判定基准由"修正后总分是否为零"明确为"实际收牌中除♣10外是否还有其他分牌"，与窝猪+全红+亮♥A+亮变=0 的示例兼容。
2. **修复矛盾②**：亮牌首轮限制的作用域由"本局"修正为"每副牌"。
3. **修复矛盾③**：删除 9.1 表格中重复且含糊的"双方同时分别满足正/负阈值"行，补全对称组合（A≥+1000 且 B≤-1000）。
4. **冻结默认值**：`autoLightLastOne`、全亮定义、平局裁决、8局同猪头裁决、5局加赛规则、兜底领出规则等全部给出临时默认。
5. **新增对局过程管理章节**：限时、超时、断线重连、真人离场 AI 接管（V1.0 缺失）。
6. **信息可见性提升为接口级约束**（原仅 UI 层描述），并补充 AI 信息集定义。
7. **新增数据模型与状态机章节**，补充单局副数上限兜底。
8. 明确：允许一名玩家亮多张关键牌；满贯一律在整副牌结算时判定；亮牌阶段全员提交后提前揭晓。
9. 术语统一：整场对局称"**盘**"，盘内固定局数，局内含若干副牌。

## 1. 概述

### 1.1 项目目标

开发一款4人2v2中式拱猪对家赛。游戏以"局"为画猪头段：每局内可连续打多副牌，小分累计用于判定画猪头条件；每达到画猪头条件，本局结束，负方被画相应数量猪头，双方小分清零，进入下一局。最终在规定局数内比较双方累计猪头数，猪头少者获胜。

核心设计：
- 只做南北 vs 东西固定对家赛，不做个人赛。
- 小分不是最终胜负依据，只用于触发画猪头和决定画几头。
- 满贯为个人事件，但触发后本队立即赢下本局，给对方画猪头。
- 支持暗亮：亮牌阶段结束前，其他方只能看到"已亮牌背/数量"，不能看到具体牌。

### 1.2 术语定义

| 术语 | 定义 |
|---|---|
| 盘 | 整场对赛，由固定局数组成（5局制/8局制）；最终比较双方猪头总数 |
| 局 | 画猪头段。从0分开始，可包含多副牌，直到某副牌结算后触发画猪头或满贯；画头后本局结束，小分清零 |
| 副牌 | 一次发牌→亮牌→出牌→结算的完整过程 |
| 小分 | 每副牌个人/团队计分，仅用于判定画猪头条件，不直接决定最终胜负 |
| 猪头 | 本局负方被记录的惩罚标记；盘终猪头少者胜 |
| 窝猪 | 亮猪者本人最终自己收下♠Q，猪分记-400 |
| 满贯 | 单个玩家集齐猪、羊、变压器、全部13张红桃；触发后本队立即赢下本局 |
| 全亮 | 本局四张关键牌均被亮出（含自动亮），不论谁亮 |
| 暗亮 | 亮牌提交阶段互相不可见具体牌，亮牌阶段结束后统一公开 |
| 差值分 | 可选计分模式，V2.0 不采用；固定团队原始和累计 |

## 2. 用户角色与座位

1. 固定4个座位：南、北、东、西。出牌顺序为逆时针：南→东→北→西。
2. 队伍固定：南+北为一队（下称 A 队）；东+西为一队（下称 B 队）。
3. 任意座位可为真人或 AI 机器人，支持真人+真人、真人+AI、AI+AI 混合。
4. V2.0 不提供单打模式、不提供自由换座组队。

---

## 3. 总体游戏流程

```
创建对局（选择赛制、座位真人/AI）
→ 盘开始
   └─ 新局开始，双方小分清零
      → 发牌（每人13张）
      → 亮牌阶段（暗亮提交，全员提交后提前揭晓）
      → 亮牌揭晓（统一公开正面）
      → 出牌阶段（13墩）
      → 副牌结算
         ├─ 满贯判定（结算时判定）：触发则本队赢下本局，给对方画1或2头
         ├─ 普通计分：个人分→团队小分累计
         ├─ 画猪头判定：达到条件则画头，本局结束
         └─ 未触发：继续下一副牌，小分继续累计
      → 本局结束：记录猪头，小分清零
      → 判断赛制是否结束：未结束则进入下一局
→ 盘结束：统计双方总猪头，少者胜；同猪头按赛制规则裁决
```

## 4. 对局规则

### 4.1 发牌与领出

1. 一副牌52张，无大小王，随机洗牌后每人13张。
2. 每局第一副牌：持有♣2的玩家领出，且首引必须出♣2。
3. 局内后续副牌：上一副牌拿到猪（♠Q）的玩家领出，领出花色不限。
4. 若上一副因满贯结束，本局随即结束，不进入下一副；新局第一副重新按♣2规则。
5. 画猪头后本局结束，新局第一副重新按♣2规则。

### 4.2 亮牌规则

#### 4.2.1 可亮牌
♠Q猪、♦J羊、♣10变压器、♥A红桃A。

#### 4.2.2 亮牌阶段
1. 发牌后进入亮牌阶段，玩家自主选择亮/不亮，**允许一名玩家同时亮多张**关键牌。
2. **暗亮**：亮牌阶段未结束时，自己可见自己亮牌正面；其他方只能看到"已亮牌背/数量"，不能看到具体牌种（接口级约束，见第9章）。
3. 亮牌阶段结束后，统一公开所有亮牌正面，之后所有人可见。
4. 提交后不可撤回；超时未提交视为不亮；**全部4家提交后立即揭晓**，无需等满计时。
5. 自动亮：四张可亮牌已亮3张时，若配置 `autoLightLastOne` 开启（V2.0 默认**开启**⚠️），由服务端在亮牌截止时判定剩余1张自动亮，揭晓时公开。
6. 固定为"揭晓后公开正面"，不做"出牌阶段仍隐藏具体亮牌"的扩展模式。
7. 自动亮的牌与其他亮牌**同等适用** 4.2.4 首轮限制，并计入"已亮牌背/数量"的展示。

#### 4.2.3 亮牌对计分的影响
亮牌是个人行为，只影响拿牌者计分；满贯画猪头为团队结果，属于例外（见 5.6）。

#### 4.2.4 亮牌首轮限制
1. **每副牌**中，某花色第一次出现的一墩，该花色中被亮过的牌**不能领出，也不能跟牌**。
2. 例外①（跟牌）：若玩家手中该花色仅剩这一张亮牌，跟牌时必须出。
3. 例外②（领出）：玩家不允许主动领出该花色；若轮到领出且手中只剩受限制亮牌、无其他合法领出牌，**兜底允许领出该亮牌**，避免死锁（V2.0 默认如此⚠️，UI 需提示）。
4. 该限制对亮猪、亮羊、亮变、亮♥A一致适用；自动亮的牌同样适用。

### 4.3 出牌与收墩

1. 一墩：领出一家出一张，逆时针依次跟牌，4张为一墩，共13墩。
2. 强制跟牌：有领出花色必须跟同花色；没有该花色可任意垫其他花色，垫牌视为本墩最小。
3. 同花色点数最大者赢墩；无将牌，不同花色不比较大小。
4. 赢墩者收下本墩所有分牌，并获得下一墩领出权。
5. 一墩分牌归赢墩个人，结算时先算个人分，再相加为团队小分。
6. 牌大小：A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3 > 2。

## 5. 计分规则

### 5.1 基础分值

| 牌 | 名称 | 基础分 | 亮牌后 |
|---|---|---|---|
| ♠Q | 猪 | -100 | -200 |
| ♦J | 羊 | +100 | +200 |
| ♣10 | 变压器 | 特殊倍率 | 倍率升级（×2→×4） |
| ♥A | 红桃A | -50 | -100（即红桃分值×2，含♥A自身） |
| ♥K | 红桃K | -40 | -80 |
| ♥Q | 红桃Q | -30 | -60 |
| ♥J | 红桃J | -20 | -40 |
| ♥10~♥5 | 红桃10~5 | 各-10 | 各-20 |
| ♥4~♥2 | 红桃4~2 | 0 | 0 |

全部红桃原始总分：-200。

### 5.2 个人分计算顺序

1. 统计四名玩家各自收下的分牌。
2. 判满贯：若触发，进入满贯分支（5.6），本队赢下本局，本副不再进行普通计分。
3. 判全红（5.4）。
4. 应用亮牌修正：亮猪、亮羊、亮♥A（含红桃翻倍）。
5. 处理窝猪（5.5）：亮猪者自收猪最终-400，替代亮猪-200。
6. 处理变压器倍率（5.3）：对该玩家修正后最终非零总分×2或×4；满足独拿条件则+50/+100。
7. 得到个人本副原始分。
8. 团队本副小分 = 南分+北分（A队），或东分+西分（B队）；固定团队原始和累计。
9. 将团队本副小分累加到本局团队小分。

### 5.3 变压器规则

1. 玩家拿到♣10，且**实际收下的分牌中除♣10外还有其他分牌**：该玩家本副修正后非零总分×2；亮变压器则×4。
2. 玩家实际收下的分牌**只有♣10一张**（无任何其他分牌，无论分数是否为0）：基础+50；亮变压器后+100。注意：独拿判定以**实际收牌**为准，不以修正后总分是否为零为准（与 5.5 示例兼容）。
3. 变压器放大的是"拿到它的那个玩家"的个人分，不直接放大团队分。

### 5.4 全红规则

1. 单个玩家收集全部13张红桃：红桃总分从-200反转为+200；若♥A亮牌，先翻倍至-400再反转为+400。
2. 全红只反转红桃分数，猪分照常计算；若同时窝猪，按 5.5 叠加。
3. 全红为个人事件，不支持两人合全红。

### 5.5 窝猪规则

1. 仅当**亮猪者本人最终自己收下♠Q**时触发窝猪，猪分记-400（替代亮猪-400修正流程中的-200）。
2. 亮猪后被同伴收下，不算窝猪；同伴按亮猪后的-200计猪分。
3. 自动亮的猪若本人自收，**算窝猪**（V2.0 默认⚠️）。
4. 窝猪与全红同时发生：先算全红红桃反转分，再叠加窝猪-400。
   - 窝猪+全红 = -400 + 200 = -200；亮♥A则 -400 + 400 = 0。
5. 窝猪后若该玩家拿变压器且亮变，对最终个人非零总分应用×4。
   - 窝猪-400且亮变 → -1600；窝猪+全红=-200且亮变 → -800；窝猪+亮♥A全红=0且亮变 → 0（修正后总分为0，×4仍为0，不触发5.3第2条，见5.3判定基准）。
6. 满贯触发时，不触发窝猪，不计算猪负分。

### 5.6 满贯规则

1. 满贯条件：单个玩家集齐猪、羊、变压器、全部13张红桃。必须个人拿齐，不支持合满贯。
2. 满贯一律在**整副牌结算时**判定，不做墩内中断。
3. 满贯优先级最高：触发后**本队立即赢下本局**，不结算普通小分，不触发窝猪，不再检查小分阈值。
4. 满贯给对方画猪头：
   - 非全亮：对方画1头。
   - 四张全亮：对方画2头。
5. "四张全亮"定义：本局四张关键牌均被亮出（含自动亮），不论谁亮（V2.0 确认采用此定义⚠️）。
6. 满贯时满贯者自己得猪也不计负分；普通分牌仅可做展示/复盘，不参与本局小分和画头判定。
7. 满贯本局结束后，双方小分清零，进入下一局。

## 6. 画猪头判定与一局结束

### 6.1 判定流程

每副牌结算后：
1. 先判满贯（5.6）：触发则按 6.3 处理，结束本局。
2. 未触发满贯，累加团队小分后按 6.2 表判定。
3. 触发画头则本局结束；未触发则继续下一副牌。

### 6.2 普通画猪头条件

设 A 队、B 队本局累计小分为 SA、SB，未达标指小分在 (-1000, +1000) 区间内：

| 触发条件 | 画头结果 | 本局胜者 |
|---|---|---|
| 仅 SA ≤ -1000 | A队画1头 | B队 |
| 仅 SA ≥ +1000 | B队画2头 | A队 |
| 仅 SB ≤ -1000 | B队画1头 | A队 |
| 仅 SB ≥ +1000 | A队画2头 | B队 |
| SA ≤ -1000 且 SB ≥ +1000 | A队画3头 | B队 |
| SA ≥ +1000 且 SB ≤ -1000 | B队画3头 | A队 |
| SA ≥ +1000 且 SB ≥ +1000 | 双方各画2头 | 新增猪头少者；相同按 6.4 裁决 |
| SA ≤ -1000 且 SB ≤ -1000 | 双方各画1头 | 新增猪头少者；相同按 6.4 裁决 |

说明：单队不可能同时满足正负两条阈值，无需额外规则。

### 6.3 满贯画头

满贯优先于普通阈值：触发满贯即本队赢下本局，给对方画1头（非全亮）或2头（四张全亮），不再检查 6.2 表。

### 6.4 新增猪头相同时的本局裁决（临时默认⚠️）

双方本局新增猪头数相同时，依次比较：
1. 本局双方累计小分，小分更低（更负）的一方为本局负者；
2. 若小分也相同，本局判和局，双方各记本局胜负为平。

### 6.5 一局兜底终止（新增⚠️）

单局设副数上限（默认20副）。达到上限仍未触发画头时：
1. 比较双方本局累计小分，小分更低方被画1头，本局结束；
2. 小分相同则双方各画1头。

### 6.6 画头后处理

1. 本局立即结束。
2. 记录双方本局新增猪头数，累加到本盘总猪头。
3. 双方本局小分清零。
4. 进入下一局；新局第一副由持♣2者领出且必须出♣2。

## 7. 赛制与最终胜负

### 7.1 5局制

1. 固定进行5局，累计双方总猪头数。
2. 5局后猪头总数少者获胜。
3. 若5局后双方总猪头数相同，进入**加赛**（临时默认⚠️）：
   - 加赛局采用"突然死亡"：每加赛1局，总猪头少者立即获胜。
   - 若某加赛局双方新增猪头相同（按6.4裁决为和局），则继续加赛，直至分出胜负。
   - 加赛局产生的猪头正常累计入总猪头。

### 7.2 固定8局制

1. 固定进行8局，累计双方总猪头数。
2. 8局后猪头总数少者获胜。
3. 若8局后双方总猪头数相同，判**最后一局输者负**。最后一局输者定义（V2.0 默认⚠️）：
   1. 最后一局新增猪头多者为本局输者；
   2. 若最后一局双方新增猪头相同（和局），依次向前回溯最近一局有胜负的局，该局的负者为输者；
   3. 若整盘无胜负局（极端情况），双方判和。

### 7.3 本局胜负用途

本局胜负用于：记录本局谁赢、固定8局同猪头时回溯裁决、展示与战绩。最终胜负仍以总猪头数少者为准。

### 7.4 计分模式备注

V2.0 固定采用团队**原始和**累计。注意：该模式下正分（羊、变压器、全红）同样会把队伍推向被画头，玩家策略上会主动规避正分牌。差值分模式列为后续可选；产品若希望回归"抢羊抢变"的传统体验，建议优先评估切换。

## 8. 对局过程管理（新增）

### 8.1 限时

| 环节 | 时限（默认，可配置） |
|---|---|
| 亮牌阶段 | 30秒 |
| 每墩出牌 | 20秒 |

### 8.2 超时处理

1. 亮牌超时未提交：视为不亮。
2. 出牌超时：由系统自动打出该玩家当前最小合法牌（垫牌时打出非分牌优先），对局不中断。
3. 系统代打需在 UI 明确标记，复盘可见。

### 8.3 断线重连

1. 玩家断线后保留座位 60 秒，期间由 AI 按 8.2 规则代打。
2. 60 秒内重连：恢复正常操作，历史牌局状态全量同步。
3. 超时未归：判为离场，该座位由 AI 永久接管至本盘结束。

### 8.4 真人离场

真人主动退出按 8.3 第3条处理，不可中途换人。

## 9. 信息可见性与AI

### 9.1 信息集（接口级约束）

服务端按阶段下发信息，任何客户端（含 AI）不得获取超出下表的信息：

| 阶段 | 可见信息 |
|---|---|
| 暗亮阶段 | 自己13张手牌、自己亮牌正面、每家"已亮N张"（仅数量与牌背，不含牌种） |
| 亮牌揭晓后 | 所有亮牌正面 |
| 出牌阶段 | 各家剩余牌数、各墩已出牌、历史出牌记录 |
| 结算后 | 各玩家本副分牌明细与个人分 |

暗亮阶段其他方**不能通过任何接口**获取具体亮牌——此为验收硬约束，不仅限于 UI 隐藏。

### 9.2 AI约束

1. AI 只接收与真人玩家相同的信息集，不得读取未公开手牌、未揭晓亮牌、其他玩家手牌或牌堆剩余牌。
2. AI 需支持合法出牌、基本跟牌/垫牌、基础计分规避。
3. 高级AI亮牌策略、关键牌概率推断、搭档信号解读列为后续阶段。

### 9.3 信号系统

V2.0 不做信号系统：UI 不展示信号解读，AI 不依赖信号。

## 10. 数据模型与状态机（新增）

### 10.1 状态机

```
盘(Match) ──包含──> 局(Round) ──包含──> 副(Deal)
副的状态机：
  发牌 → 暗亮 → 揭晓 → 出牌(领出→跟牌×3 → 收墩)×13 → 结算
        ↑__________（未画头）__________|
局结束 → 新局 或 盘结束 → 终局结算
```

### 10.2 核心实体（最小集）

- Match：赛制、局数上限、双方总猪头、状态。
- Round：本局双方小分、本局新增猪头、副数计数、状态。
- Deal：四家手牌、亮牌记录（含自动亮标记）、13墩记录、领出权、结算结果。
- Trick：领出者、四张出牌、赢墩者、分牌归属。
- Player：座位、真人/AI、断线状态。

### 10.3 回放与审计

1. 每副牌记录完整操作序列（含系统代打标记），支持整盘回放。
2. 发牌结果记录随机种子，支持重现与审计。

## 13. 验收要点

1. 暗亮阶段其他方无法通过**任何接口**获取具体亮牌。
2. 亮牌首轮限制正确作用于**每副牌**：不能领出、不能跟牌；唯一亮牌跟牌必须出、不能主动领出；兜底领出不死锁。
3. 窝猪仅亮猪者自收触发-400；被同伴收按-200；自动亮猪自收算窝猪。
4. 数值用例：窝猪+全红=-200；窝猪+全红+亮♥A=0；窝猪+亮变=-1600；窝猪+全红+亮♥A+亮变=0（按5.3独拿判定基准）；变压器独拿+50/亮变+100。
5. 满贯在结算时判定，立即结束本局，不结算普通小分，不触发窝猪，给对方画1或2头。
6. 普通画猪头表（6.2）全组合正确，含对称组合；画头后小分清零。
7. 局内未画头可多副累计，下一副由上一副拿猪者领出；单局达副数上限按6.5兜底。
8. 5局制/8局制最终猪头比较和同猪头裁决（含加赛、回溯）正确。
9. 超时、断线重连、离场AI接管符合第8章。
10. 任意座位真人/AI混合可正常对局；AI 不超出公开信息集。
11. 无单打、无自由组队入口。
12. 支持整盘回放与发牌种子审计。

# 模块 A：分数临界亮牌概率规则（含殉爆 / 冲锋分支）

**定位**：优先级最高的前置否决层。本模块**只读分数，不看手牌**，输出四类牌（猪、红桃 A、羊、变压器）的基准概率 \(P_{base}\)，以及一个**分支旗标**，供后续牌型、牌点、满贯、弹性各模块做乘性修正。

## 一、变量与归一化

胜负边界：\(S_{max}=+1000\)，\(S_{min}=-1000\)。

| 变量 | 含义 |
| --- | --- |
| \(S_{me}\) | 我方队伍当前总分 |
| \(S_{op}\) | 敌方队伍当前总分 |
| \(r_{me}^-\) | 我方距负向出局线的归一化距离 |
| \(r_{me}^+\) | 我方距正向胜利线的归一化距离 |

\[
r_{me}^-=\frac{S_{me}-S_{min}}{0-S_{min}}=\frac{S_{me}+1000}{1000},\qquad
r_{me}^+=\frac{S_{max}-S_{me}}{S_{max}-0}=\frac{1000-S_{me}}{1000}
\]

\[
r_{op}^-=\frac{S_{op}+1000}{1000},\qquad r_{op}^+=\frac{1000-S_{op}}{1000}
\]

读数口径（关键，全部后续判定以此为准）：

- \(r^-\to 0\)：已贴到 −1000，基本出局；\(r^-=1\)：正好 0 分；\(r^->1\)：正分。
- \(r^+\to 0\)：已贴到 +1000，基本锁定胜局；\(r^+=1\)：正好 0 分。

概率载体统一用 Sigmoid，保证平滑无跳变：

\[
\sigma(x)=\frac{1}{1+e^{-x}}\in(0,1)
\]

\[
P_{base,羊}=0
\]

即敌方已逼近胜利线，分数层面禁止任何亮羊，后续模块无权翻案。

## 三、分支层（四条分支，判定顺序 B → C → D，均不命中才走常规）

### 分支 B：殉爆分支（我方濒临出局，反过来拉对方一起出局）

**触发条件（需同时满足）**

\[
r_{me}^-<T_{sui}\quad\text{且}\quad r_{op}^-<T_{op,sui}
\]

初值 \(T_{sui}=0.2\)（即 \(S_{me}<-800\)），\(T_{op,sui}=0.5\)（即 \(S_{op}<-500\)，对应你之前说的"哪怕只有负 500 也算数"）。

**殉爆强度**

\[
m=1-\frac{r_{me}^-}{T_{sui}}\in(0,1]
\]

\(m\to1\) 表示已贴死出局线；\(m=0.5\) 表示刚进入殉爆区。

**殉爆基准概率（改用强度直接驱动，不再计算"我方风险"项）**

\[
P_{base,变压}^{sui}=\sigma\big(k_s(2m-1)\big),\quad k_s=4
\]

\[
P_{base,hA}^{sui}=\sigma\big(k_h(2m-1)\big),\quad k_h=4
\]

\[
P_{base,猪}^{sui}=\sigma\big(k_p(2m-1)-\varepsilon\big),\quad k_p=3,\ \varepsilon=0.5
\]

羊：维持常规值（不参与殉爆，正分牌救不了局也不再制造额外变数）。

取值参考：\(m=1\to0.98\)，\(m=0.5\to0.50\)，\(m\to0\to0.02\)。

**支撑这组公式的核心原理——风险饱和**

当 \(r_{me}^-\to0\)，我方负分继续加深的边际损失趋近于 0（已在 −1000 边缘，多丢几十上百分也只是同一结果），而对敌方造成的边际损失仍是全额。因此在这种区间里，变压器与红桃 A 的"我方风险项"应从公式中整体移出，只保留"对敌杀伤"方向，这就是殉爆分支与常规模式的本质差别。变压器尤其适配：它同时放大双方分值，在我方损失已饱和、对方损失未饱和的窗口里，变压器是纯收益算子。

### 分支 C：冲锋分支（我方接近 +1000，用变压器冲线）

**触发条件**

\[
r_{me}^+<T_{chg},\quad T_{chg}=0.2\ (\text{即 } S_{me}>+800)
\]

**冲锋强度**

\[
n=1-\frac{r_{me}^+}{T_{chg}}\in(0,1]
\]

\[
P_{base,变压}^{chg}=\sigma\big(k_c(2n-1)\big),\quad k_c=4
\]

含义：越贴近 +1000，亮变压器越值——一旦本局变压器生效并结算，我方一次性越过 +1000 直接终结对局，敌方没有返程机会，等于把"胜势"加速度兑换成"确定胜利"。

**保胜压制（同区间强制生效）**

\[
P_{base,hA}^{chg}=P_{base,hA}\cdot(1-n),\qquad
P_{base,猪}^{chg}=P_{base,猪}\cdot(1-n)
\]

即：冲线阶段禁止亮负分牌，任何负分都可能在临界点把优势打回去。

羊：不低于常规值，可取 \(P_{base,羊}^{chg}=\min\big(1,\ P_{base,羊}(1+0.5n)\big)\)，正分牌在冲线阶段是加速器。

### 分支 D：绝境博弈分支（原有拖平逻辑，中等负分阶段）

**触发条件**

\[
r_{me}^-<T_{risk},\quad T_{risk}=0.4\ (\text{即 } S_{me}<-600)
\]

且**不满足分支 B**（尚未进入殉爆区间）。

\[
P_{base,猪}^{gam}=\sigma\big(-k_g(r_{me}^- - r_{op}^-)\big),\quad k_g=3
\]

\[
P_{base,hA}^{gam}=\sigma\big(-k_g'(r_{me}^- - r_{op}^-)\big),\quad k_g'=3.5
\]

\[
P_{base,变压}^{gam}=\sigma\big(k_{5g}(r_{op}^- - r_{me}^-)\big),\quad k_{5g}=3
\]

\(r_{me}^-<T_{risk}\) 这一段禁用常规值；\(r_{me}^-\ge T_{risk}\)（我方负分不到 600）时，**该分支整体关闭**，不得用这套打法放大我方风险。

### 分支互斥性与优先级

| 顺序 | 分支 | 触发 | 与其它分支关系 |
| --- | --- | --- | --- |
| 1 | B 殉爆 | \(r_{me}^-<0.2\) 且 \(r_{op}^-<0.5\) | 优先于 D，与 C 天然互斥 |
| 2 | C 冲锋 | \(r_{me}^+<0.2\) | 与 B、D 天然互斥（\(S_{me}<-800\) 与 \(S_{me}>+800\) 不可能同时成立） |
| 3 | D 绝境博弈 | \(r_{me}^-<0.4\) 且不满足 B | 被 B 覆盖 |
| 4 | 常规 | 以上都不满足 | — |

其中 B 与 D 的分界就是"拖平"与"拖死"：D 阶段我方还能靠自保把负分控制住、换取双方同时出局；B 阶段已无自保价值，目标直接切换为最大化对方损失。

## 五、自然语言规则（配套文档说明）

1. 我方离 −1000 越近，猪与红桃 A 的常规基准概率越低；羊越高；变压器在常规模式下慎用。
2. 敌方离 −1000 越近，猪、红桃 A、变压器的基准概率越高，用于施压。
3. 敌方逼近 +1000（超过 +700）时，分数层直接封死羊，基准置 0，任何牌型优势都不翻案。
4. 我方负分超过 −600 后进入绝境博弈：目标从"保分"改为"拖对方一起出局"，猪、红桃 A、变压器基准抬升。
5. **我方负分超过 −800 时升级为殉爆**：此时损失已饱和，变压器与红桃 A 的风险项整体剔除，按殉爆强度 \(m\) 直接拉高基准概率，能亮就亮，把对方一起带进出局线；但敌方负分需至少 −500 才具备殉爆价值，否则只是白送。
6. **我方接近 +1000（超过 +800）时进入冲锋**：变压器基准概率拉高，用一次结算直接终结对局；同区间强制压低猪与红桃 A，禁止在临界点自伤；羊可适度加成。
7. 我方负分不到 −600 时，一律禁用 5、6 两条里的高风险与高方差打法，只走常规分支。

## 六、与下游模块的接口约定

最终概率：

\[
P_{final}=\mathrm{clamp}\big(P_{base}\times F_{牌型}\times F_{牌点}\times F_{满贯}\times F_{弹性},\ 0,\ 1\big)
\]

其中 \(F\) 为各模块给出的修正因子，\(\mathrm{clamp}\) 截断到 \([0,1]\)。

**必须随结果下传一个分支旗标**

\[
\text{branch\_flag}\in\{\text{normal},\ \text{sui},\ \text{charge},\ \text{gamble}\}
\]

约束条款（防止下游把上游意图改回去）：

- \(flag=\text{sui}\) 时，牌型模块**不得**再以"我方负分过高、风险大"为理由压低变压器与红桃 A，这两项的修正因子取值范围限定 \(F\ge1\)。此阶段风险项已饱和，压低等于废掉殉爆。
- \(flag=\text{charge}\) 时，牌型模块对猪与红桃 A 只能维持压制或进一步压低，不得因"牌型完美"而抬升。
- 敌方胜线封锁（\(P_{base,羊}=0\)）是全局常量级否决，任何模块乘任何因子都不得使其复活。
- 其余情形按常规，牌型、牌点、满贯、弹性各自独立乘算。
